หลัง login สำเร็จ ระบบจะพามาที่ **หน้า Dashboard** ซึ่งเป็นศูนย์กลางเข้าสู่ทุกฟีเจอร์ของ ตารางสอน

<img src="/images/screens/dashboard.png" alt="หน้า Dashboard ของ ตารางสอน" />

## แถบบน (Header)

| ตำแหน่ง | รายละเอียด |
| --- | --- |
| **โลโก้ "ตารางสอน"** (ซ้ายสุด) | กดเพื่อกลับหน้า Dashboard จากหน้าใดก็ได้ |
| **🌐 ไทย** | ปุ่มสลับภาษา ปัจจุบันรองรับ ไทย / English |
| **"Academic Pro"** (ชิปสีเขียว) | ป้ายบอกแพ็กเกจปัจจุบัน กดจะพาไปที่หน้าแพ็กเกจ |
| **รูปโปรไฟล์** (ขวาสุด) | เมนู dropdown สำหรับ ตั้งค่า / ออกจากระบบ |

<Tip>
  ถ้าเห็นคำว่า **Free** แทน Academic Pro แสดงว่าคุณกำลังใช้แพ็กเกจฟรี สามารถอัปเกรดได้ที่หน้า [แพ็กเกจ](/pricing)
</Tip>

## คำทักทาย

ด้านบนซ้ายจะมีข้อความ **"สวัสดี, {ชื่อ-นามสกุล}"** และบรรทัดรอง **"ระบบจัดตารางสอนอัจฉริยะ"** — ใช้ยืนยันว่า login อยู่ในบัญชีที่ถูกต้อง หากเห็นชื่อคนอื่นหรือชื่อว่างเปล่า ให้ออกจากระบบแล้วเข้าใหม่

## การ์ดเมนูหลัก 5 ใบ

Dashboard ประกอบด้วยการ์ดเมนู 5 ใบ โดยใบซ้ายสุดขนาดใหญ่เป็น "หัวใจหลัก" ของแอป

### 1. จัดตารางสอน (การ์ดใหญ่สีเขียว)

การ์ดใหญ่ซ้ายมือคือ**ทางลัดไปสร้างหรือเปิดแฟ้มตารางสอน** — กดเพื่อเข้าสู่หน้า [แฟ้มจัดตารางสอน](/timetable/files) ซึ่งจะเห็นแฟ้มที่สร้างไว้แล้วและปุ่มสร้างใหม่

- หัวข้อ: **จัดตารางสอน**
- คำอธิบาย: **"สร้างใหม่หรือเปิดแฟ้มจัดตารางสอนที่มีอยู่"**
- ไอคอน: ช่องสี่เหลี่ยม 4 ช่อง (grid)

### 2. ข้อมูลพื้นฐานตารางสอน

การ์ดขวาบนฝั่งซ้าย — **รวมข้อมูลอ้างอิงทั้งหมด** ที่จำเป็นก่อนจัดตาราง

- หัวข้อ: **ข้อมูลพื้นฐานตารางสอน**
- คำอธิบาย: **"ครูผู้สอน ผู้เรียน ห้องเรียน รายวิชา"**
- ไอคอน: ฐานข้อมูล

กดเพื่อเข้าสู่หน้าเพิ่มข้อมูล 4 กลุ่มหลัก: [ผู้สอน](/roster/teachers), [ผู้เรียน](/roster/students), [ห้องเรียน](/roster/rooms), [รายวิชา](/roster/subjects)

### 3. พิมพ์

การ์ดขวาบน — **สำหรับพิมพ์ตารางสอนลงกระดาษ** หรือส่งออกเป็น PDF

- หัวข้อ: **พิมพ์**
- คำอธิบาย: **"พิมพ์ตารางสอน ตารางเรียน ลงกระดาษ"**
- ไอคอน: เครื่องพิมพ์

พาไปที่ [หน้าพิมพ์](/timetable/printing) ซึ่งให้เลือกแฟ้มงาน เลือกรูปแบบ และกดดูตัวอย่างก่อนพิมพ์

### 4. ดูตาราง

การ์ดขวาล่างฝั่งซ้าย — **สำหรับดูตารางแบบ view-only** แยกตามบุคคล

- หัวข้อ: **ดูตาราง**
- คำอธิบาย: **"ดูตารางสอน ตารางเรียน ตารางห้อง"**
- ไอคอน: ตา

เหมาะสำหรับครูที่ต้องการดูเฉพาะตารางสอนของตัวเอง หรือนักเรียนดูตารางเรียนห้องตัวเอง ดูที่ [ดูตาราง](/timetable/viewing)

### 5. ตั้งค่า

การ์ดขวาล่าง — **ศูนย์ตั้งค่าทั้งหมด** (โปรไฟล์, โรงเรียน, แพ็กเกจ, ผู้ใช้ร่วม)

- หัวข้อ: **ตั้งค่า**
- คำอธิบาย: **"จัดการบัญชีและการตั้งค่า"**
- ไอคอน: เฟือง

กดเพื่อเข้าสู่ [หน้าตั้งค่า](/settings/account) ซึ่งประกอบด้วย 7 แท็บย่อย
