หน้านี้ครอบคลุมส่วนที่เกี่ยวกับ **บัญชีของคุณ** — โปรไฟล์ส่วนตัว แพ็กเกจที่ใช้อยู่ ประวัติการชำระเงิน และการจัดการสมาชิกในทีม

## โปรไฟล์ของฉัน

เปิด **ตั้งค่า → โปรไฟล์ของฉัน** หรือไปตรงที่ `/settings`

<img src="/images/screens/settings-profile.jpg" alt="หน้าโปรไฟล์ของฉัน" />

ฟิลด์ในหน้านี้:

| ช่อง | คำอธิบาย |
|---|---|
| **รูปโปรไฟล์** | คลิกเพื่อเปลี่ยน — ใช้สำหรับแสดงในเมนูด้านบน |
| **ชื่อ-นามสกุล** | ใช้สำหรับลงชื่อในเอกสารและประวัติการแก้ไข |
| **ตำแหน่ง** | เช่น ครูชำนาญการ ผู้ดูแลวิชาการ |
| **อีเมล** | อีเมลที่ใช้เข้าสู่ระบบ — แก้ไม่ได้ |
| **เบอร์โทรศัพท์** | ใช้ติดต่อกลับเมื่อมีปัญหาเร่งด่วน |

กด **บันทึก** เมื่อแก้เสร็จ

## แพ็กเกจ

เปิด **ตั้งค่า → แพ็กเกจ** หรือไปตรงที่ `/settings?tab=package`

<img src="/images/screens/settings-package.jpg" alt="หน้าแพ็กเกจปัจจุบัน" />

หน้านี้แสดง:
- **แพ็กเกจปัจจุบัน** (เช่น Academic Pro)
- **ราคา** ต่อปี
- **วันที่เริ่มใช้** และ **หมดอายุ** (เหลือกี่วัน)
- ลิงก์ **เปรียบเทียบแพ็กเกจทั้งหมด** — เปิดหน้า [pricing](/pricing)

หากต้องการอัปเกรดหรือเปลี่ยนแพ็กเกจ ให้กด **เปรียบเทียบแพ็กเกจทั้งหมด** แล้วเลือกใหม่

## การชำระเงิน

เปิด **ตั้งค่า → การชำระเงิน** หรือไปตรงที่ `/settings?tab=payment`

<img src="/images/screens/settings-payment.jpg" alt="หน้าการชำระเงินและประวัติ" />

แบ่งเป็น 3 ส่วน:

### แพ็กเกจปัจจุบัน
แสดงรายละเอียดแพ็กเกจ พร้อมปุ่ม **ยกเลิกการชำระเงินอัตโนมัติ** สีแดง — กดเพื่อปิดการต่ออายุอัตโนมัติเมื่อครบกำหนด

### เติม AI Token
มี 3 แพ็กเกจ Token ให้เลือก:
- 100 tokens — ฿99 (เริ่มลองใช้)
- 500 tokens — ฿399 (พอจัดตารางทั้งภาคเรียน) — **คุ้มที่สุด**
- 1,200 tokens — ฿799 (ใช้ทั้งปีไม่ต้องเติม)

กด **ซื้อเลย** ระบบจะเปิดหน้าชำระเงินที่ปลอดภัยจาก Stripe (รองรับบัตรเครดิต/เดบิต และพร้อมเพย์) Token ใช้ได้ทันทีหลังชำระสำเร็จ ไม่หมดอายุ

### ประวัติการชำระเงิน
ตารางแสดงทุกรายการที่เคยชำระ พร้อมคอลัมน์: วันที่ · แพ็กเกจ · ประเภท · รูปแบบ · ยอดเงิน · สถานะ · ใบเสร็จ

กดที่ใบเสร็จเพื่อดาวน์โหลด PDF

<Tip>
  หากต้องการใบกำกับภาษีในรูปแบบเอกสาร หรือมีคำถามเรื่องการชำระเงิน → ติดต่อ [payment@tarangson.com](mailto:payment@tarangson.com) ก่อนชำระ
</Tip>

## จัดการผู้ใช้

เปิด **ตั้งค่า → จัดการผู้ใช้** หรือไปตรงที่ `/settings?tab=users`

<img src="/images/screens/settings-users.jpg" alt="หน้าจัดการผู้ใช้และสิทธิ์" />

### ตารางผู้ใช้
แสดงผู้ใช้ทั้งหมดในระบบ พร้อมคอลัมน์:
- **ผู้ใช้** — ชื่อและอีเมล
- **บทบาท** — เจ้าของ / ผู้จัดตาราง / ผู้ใช้งาน
- **สถานะ** — ใช้งาน / รอเชิญ

มุมขวาบนมีปุ่ม **เชิญผู้ใช้ใหม่** — กดเพื่อส่งคำเชิญทางอีเมลให้สมาชิกใหม่

### บทบาทและสิทธิ์

ระบบกำหนดบทบาทไว้ 3 ระดับ:

| บทบาท | สิทธิ์หลัก |
|---|---|
| **เจ้าของ** | ทำได้ทุกอย่าง รวมถึงจัดการผู้ใช้และแพ็กเกจ |
| **ผู้จัดตาราง** | แก้ไขข้อมูลและจัดตาราง แต่จัดการผู้ใช้/แพ็กเกจไม่ได้ |
| **ผู้ใช้งาน** | ดูข้อมูลและพิมพ์เท่านั้น แก้ไม่ได้ |

### กำหนดสิทธิ์การเข้าถึงเมนู

ใต้ตารางผู้ใช้คือ **สิทธิ์การเข้าถึงเมนู** — กำหนดว่าแต่ละบทบาทเข้าเมนูใดได้บ้าง โดยติ๊กช่องในแต่ละแถว

หมวดหมู่ที่ปรับสิทธิ์ได้:
- **ข้อมูลโรงเรียนพื้นฐาน** — ตารางเรียนพื้นฐาน · ครูผู้สอน · นักเรียน · ห้องเรียน · วิชาเรียน
- **จัดตารางสอน** — เริ่มจัดตารางสอนใหม่ · จัดตารางสอน · จัดการแฟ้มงาน

<Note>
  ระบบจะบันทึกการเปลี่ยนแปลงสิทธิ์โดยอัตโนมัติ — ไม่ต้องกดปุ่มบันทึกเพิ่ม
</Note>

## ออกจากระบบ

กดรูปโปรไฟล์ที่มุมขวาบน → เลือก **ออกจากระบบ** — ระบบจะกลับไปหน้าเข้าสู่ระบบ
