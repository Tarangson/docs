## 1. โปรไฟล์ของฉัน

<img src="/images/screens/settings.png" alt="หน้าโปรไฟล์ของฉัน" />

ข้อมูลส่วนตัวของ**ผู้ใช้ที่กำลัง login อยู่** (แยกจากข้อมูลโรงเรียน)

### ส่วนรูปโปรไฟล์

วงกลมใหญ่กลางหน้า — **คลิกที่รูปเพื่อเปลี่ยน** รองรับไฟล์ .jpg / .png / .webp ขนาดไม่เกิน 5 MB ระบบจะ crop เป็นวงกลมโดยอัตโนมัติ

### ฟิลด์ในฟอร์ม

| ช่อง | หมายเหตุ |
| --- | --- |
| **ชื่อ-นามสกุล \*** | ชื่อที่จะแสดงในแอปและเอกสาร |
| **ตำแหน่ง** | เช่น "ผู้ช่วยผู้อำนวยการ" — optional |
| **อีเมล** | **ไม่สามารถแก้ไข** (ผูกกับบัญชี) |
| **เบอร์โทรศัพท์** | สำหรับติดต่อกลับ |

### ปุ่มบันทึก

กดปุ่ม **"บันทึก"** สีเขียวล่างขวาของฟอร์ม

<Tip>
  ต้องการเปลี่ยนอีเมลที่ใช้ login? ต้องติดต่อฝ่ายสนับสนุนที่ [support@tarangson.com](mailto:support@tarangson.com) — ไม่สามารถเปลี่ยนเองในแอป
</Tip>

## 2. การชำระเงิน

แท็บนี้รวมประวัติการชำระเงินและการออกใบกำกับภาษี

### ประวัติการชำระ

ตารางแสดงรายการทั้งหมด:

| คอลัมน์ | ความหมาย |
| --- | --- |
| **วันที่** | วันที่ชำระเงิน |
| **รายการ** | ชื่อแพ็กเกจ (เช่น "Academic Pro — รายปี") |
| **จำนวนเงิน** | บาท รวม VAT |
| **สถานะ** | ชำระแล้ว / รอตรวจสอบ / ยกเลิก |
| **ใบเสร็จ/ใบกำกับ** | ปุ่มดาวน์โหลด PDF |

### วิธีชำระเงินที่รองรับ

- **QR PromptPay** — โอนและ upload สลิป ระบบตรวจสอบอัตโนมัติภายใน 1-2 ชั่วโมง
- **โอนผ่านธนาคาร** — โอนเข้าเลขบัญชีที่ระบบแจ้ง แล้วแนบสลิปในแอป
- **บัตรเครดิต/เดบิต** — ตัดบัตรทันที (รองรับ Visa / MasterCard)

### ออกใบกำกับภาษี

ก่อนชำระเงิน ให้ติ๊ก **"ออกใบกำกับภาษีเต็มรูปแบบ"** แล้วกรอก:

- ชื่อนิติบุคคล
- เลขผู้เสียภาษี 13 หลัก
- ที่อยู่สำนักงานใหญ่
- สาขา (ถ้ามี)

## 3. จัดการผู้ใช้ (ผู้ใช้ร่วม)

<img src="/images/screens/settings-users.png" alt="จัดการผู้ใช้" />

ฟีเจอร์นี้ให้ **เจ้าของโรงเรียน** เชิญครูคนอื่นเข้ามาช่วยจัดตารางได้ โดยสามารถกำหนดสิทธิ์ละเอียดในแต่ละส่วน

### ปุ่ม "+ เชิญผู้ใช้" (มุมขวาบน)

กดเพื่อเปิด dialog:

| ช่อง | หมายเหตุ |
| --- | --- |
| **อีเมลผู้ถูกเชิญ \*** | ต้องเป็นอีเมลที่จะใช้ login เข้าระบบ |
| **บทบาท** | **เจ้าของ** / **ผู้จัดการ** / **ผู้ดู** |
| **ข้อความเชิญ (ทางเลือก)** | ข้อความสั้น ๆ แนบไปกับอีเมล |

กด **ส่งคำเชิญ** — ผู้ถูกเชิญจะได้รับเมลพร้อมลิงก์ยืนยัน

### ตารางผู้ใช้ปัจจุบัน

แสดงรายชื่อผู้ใช้ทั้งหมดที่อยู่ในโรงเรียนนี้ พร้อม:

- **ผู้ใช้** — อีเมล
- **บทบาท** — เจ้าของ / ผู้จัดการ / ผู้ดู
- **สถานะ** — ใช้งาน / รอยืนยัน
- **ปุ่มถอดออก** — เฉพาะเจ้าของเท่านั้นที่กดได้

### ตารางสิทธิ์ละเอียด

ด้านล่างมีตารางสิทธิ์สำหรับ**กำหนดสิทธิ์เฉพาะหมวด** เช่น ผู้ใช้คนหนึ่งอาจเป็น **ผู้จัดการ** เฉพาะ "รายวิชา" แต่เป็น **ผู้ดู** เฉพาะ "ตารางสอนทั้งหมด"

| หมวด | เจ้าของ | ผู้จัดการ | ผู้ดู |
| --- | :---: | :---: | :---: |
| **ข้อมูลโรงเรียน** | ✅ | ☑ | ☐ |
| **ตารางสอนทั้งหมด** | ✅ | ☑ | ☐ |
| **ครูผู้สอน** | ✅ | ☑ | ☐ |
| **ห้องเรียน** | ✅ | ☑ | ☐ |
| **ผู้เรียน** | ✅ | ☑ | ☐ |
| **รายวิชา** | ✅ | ☑ | ☐ |

- ☐ = ไม่มีสิทธิ์  ☑ = มีสิทธิ์  ✅ = มีสิทธิ์เต็ม (เปลี่ยนไม่ได้)

### บทบาทโดยย่อ

| บทบาท | สิทธิ์ |
| --- | --- |
| **เจ้าของ** | ทุกอย่าง รวมการชำระเงินและการเชิญผู้ใช้ (มีได้เพียง 1 คนต่อโรงเรียน) |
| **ผู้จัดการ** | แก้ไขข้อมูลและตารางสอนได้ แต่ไม่สามารถลบโรงเรียนหรือชำระเงิน |
| **ผู้ดู** | ดูอย่างเดียว ไม่สามารถแก้ไข |

## ถอดผู้ใช้ออก

ในแถวผู้ใช้ที่ต้องการถอด — กดปุ่มจุดสามจุด (⋮) → **"ถอดออก"** → ยืนยัน ผู้ใช้จะถูกตัดสิทธิ์การเข้าถึงทันที แต่**ข้อมูลที่เขาสร้างไว้จะยังอยู่ในโรงเรียน**
