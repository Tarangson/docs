หน้า **ตั้งค่า** (`/settings`) มีแถบด้านซ้ายเรียงตามกลุ่ม — หัวข้อนี้ครอบคลุม 3 แท็บภายใต้กลุ่ม **"ตั้งค่าโรงเรียน"**: ข้อมูลโรงเรียน / ที่อยู่ / ผู้ติดต่อ

## โครงสร้างเมนูตั้งค่า (Sidebar ซ้าย)

```
โปรไฟล์
  • โปรไฟล์ของฉัน

ตั้งค่าโรงเรียน
  • แพ็กเกจ              ← ดูที่ pricing
  • ข้อมูลโรงเรียน        ← ในหน้านี้
  • ที่อยู่                ← ในหน้านี้
  • ผู้ติดต่อ              ← ในหน้านี้

การเงิน
  • การชำระเงิน          ← ดูที่ account

ผู้ใช้งาน
  • จัดการผู้ใช้          ← ดูที่ account
```

## 1. ข้อมูลโรงเรียน

<img src="/images/screens/settings-school.png" alt="ข้อมูลโรงเรียน" />

กรอกข้อมูลนิติบุคคลของสถานศึกษา — ใช้ในเอกสารพิมพ์และใบกำกับภาษี

### ฟิลด์ในหน้านี้

| ช่อง | ระบุ | หมายเหตุ |
| --- | --- | --- |
| **ชื่อเต็ม (ไทย) \*** | ชื่อทางการภาษาไทย | จำเป็น · ใช้ในหัวกระดาษพิมพ์ |
| **ชื่อเต็ม (English)** | ชื่อภาษาอังกฤษ | ถ้ากรอก จะใช้ในเอกสารภาษาอังกฤษ |
| **รหัสโรงเรียน (ไทย)** | รหัสสถานศึกษาในระบบ ศธ. | ถ้ามี |
| **รหัสโรงเรียน (English)** | School code | สำหรับ int'l |
| **ประเภทโรงเรียน** | radio — **รัฐบาล / เอกชน / ราชการ / เทศบาล / อื่นๆ** | เลือก 1 ตัว |
| **ระดับชั้น** | checkbox — **อนุบาล / ประถม / มัธยมต้น / มัธยมปลาย** | เลือกได้หลายระดับ |
| **เว็บไซต์โรงเรียน** | URL | ถ้ามี จะลิงก์ในเอกสารได้ |
| **เกี่ยวกับโรงเรียน** | textarea สั้น ๆ | ถ้ามี |

### การบันทึก

กดปุ่ม **"บันทึก"** ที่มุมล่างของฟอร์ม — ระบบจะแสดง toast สีเขียวเมื่อบันทึกสำเร็จ

## 2. ที่อยู่

<img src="/images/screens/settings-address.png" alt="ตั้งค่าที่อยู่โรงเรียน" />

ที่อยู่ของโรงเรียนใช้ใน **เอกสารราชการ, ใบกำกับภาษี, หัวกระดาษพิมพ์**

### ที่อยู่หลัก (สำหรับติดต่อ)

| ช่อง | หมายเหตุ |
| --- | --- |
| **ชื่อ** | ชื่อย่อที่จะแสดง (เช่น "ที่ตั้งหลัก") |
| **บ้านเลขที่** | เลขที่อาคาร |
| **ถนน/ซอย** | ถนนที่ตั้ง |
| **ตำบล/แขวง** | |
| **อำเภอ/เขต** | |
| **จังหวัด** | dropdown 77 จังหวัด |
| **รหัสไปรษณีย์** | 5 หลัก |

### ที่อยู่จดทะเบียน (แยกต่างหาก)

ถ้าที่อยู่จดทะเบียน**ต่างจาก**ที่อยู่หลัก (เช่น โรงเรียนเอกชนที่จดทะเบียนในนามบริษัท) ให้กรอกในส่วนนี้ — ระบบจะใช้ที่อยู่จดทะเบียนในใบกำกับภาษี

### ติ๊กเพื่อใช้ที่อยู่เดียวกัน

มี checkbox **"ใช้ที่อยู่เดียวกับที่อยู่หลัก"** — เปิดเพื่อ copy ค่าจากบล็อกบนโดยอัตโนมัติ

## 3. ผู้ติดต่อ

<img src="/images/screens/settings-contact.png" alt="ผู้ติดต่อ" />

ข้อมูลผู้ติดต่อหลัก + ช่องทางสื่อสาร

### บล็อก "ข้อมูลผู้ติดต่อ"

| ช่อง | หมายเหตุ |
| --- | --- |
| **ชื่อ-นามสกุล \*** | ชื่อผู้ติดต่อหลัก (มักเป็นครูผู้ดูแลระบบ) |
| **ตำแหน่ง \*** | เช่น "ผู้ช่วยผู้อำนวยการวิชาการ" |
| **เบอร์โทรศัพท์ \*** | 10 หลัก |
| **อีเมล \*** | ใช้สำหรับการแจ้งเตือนและสนับสนุน |

### บล็อก "ผู้ติดต่อเดียวกับโปรไฟล์"

มี checkbox ให้ติ๊กเพื่อ **ใช้ข้อมูลจากโปรไฟล์ของฉันเป็นผู้ติดต่อ** — ประหยัดเวลาหากคุณเองเป็นผู้ประสาน

### ช่องทางอื่น ๆ

- **เว็บไซต์**
- **LINE / LINE OA ID**
- **Facebook**
- **Instagram**

---

## บันทึกการเปลี่ยนแปลง

ทั้ง 3 แท็บมีปุ่ม **"บันทึก"** แยกจากกัน — แก้ไขแล้วต้องกดบันทึกทีละแท็บ ไม่มี save all

<Warning>
  หากสลับแท็บโดยไม่กดบันทึก การแก้ไขจะหายทันที ระบบจะเตือนด้วย dialog ถ้ามีข้อมูลค้าง
</Warning>
