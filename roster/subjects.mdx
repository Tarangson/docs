หน้า **รายวิชา** คือทะเบียนวิชาที่เปิดสอนในโรงเรียน เช่น ภาษาไทย คณิตศาสตร์ วิทยาศาสตร์ ภาษาอังกฤษ — ใช้เลือกเมื่อจัดตาราง

เปิดได้จาก **Dashboard → ข้อมูลพื้นฐานตารางสอน → รายวิชา** หรือเข้าตรงที่ `/base/subjects`

<img src="/images/screens/subjects-list.jpg" alt="หน้ารายการรายวิชา" />

## ส่วนประกอบของหน้า

### แถบเครื่องมือด้านบน
ปุ่มเหมือนหน้าผู้สอน — **จัดการฟิลด์ · แม่แบบ · นำเข้า · ส่งออก · + เพิ่มวิชา**

### ตารางรายการ

คอลัมน์มาตรฐาน:
- **ลำดับ**
- **สี** — สีประจำวิชา
- **รหัสวิชา** — เช่น TH101, MA102, EN101
- **ชื่อรายวิชา** — ชื่อเต็ม (เช่น "ภาษาไทยพื้นฐาน 1")
- **หมวด/ฝ่าย** — กลุ่มสาระที่วิชานี้สังกัด
- **AA** — ตัวย่อ ใช้แสดงในตารางที่พื้นที่จำกัด

## เพิ่มวิชาใหม่

กด **+ เพิ่มวิชา** มุมขวาบน

ฟิลด์ที่ต้องกรอก:

| ช่อง | จำเป็น | ตัวอย่าง |
|---|---|---|
| **รหัสวิชา** | ✅ | TH101, MA101, EN101 |
| **ชื่อรายวิชา** | ✅ | ภาษาไทยพื้นฐาน 1 |
| **หมวด/ฝ่าย** | ✅ | ภาษาไทย / คณิตศาสตร์ / วิทยาศาสตร์ |
| **ตัวย่อ (AA)** | — | ภท1, MA1 |

## ระบบรหัสวิชาที่แนะนำ

ใช้รหัส 5 ตำแหน่ง — 2 ตัวอักษร + 3 ตัวเลข เช่น:

| รหัส | วิชา |
|---|---|
| TH101 | ภาษาไทย ม.ต้น เทอม 1 |
| TH201 | ภาษาไทย ม.ปลาย เทอม 1 |
| MA101 | คณิตศาสตร์พื้นฐาน |
| MA102 | คณิตศาสตร์เพิ่มเติม |
| SC101 | วิทยาศาสตร์ทั่วไป |
| SC201 | ฟิสิกส์ |
| SC202 | เคมี |
| SC203 | ชีววิทยา |
| EN101 | ภาษาอังกฤษพื้นฐาน |
| SO101 | สังคมศึกษา ศาสนาและวัฒนธรรม 1 |
| HP101 | สุขศึกษาและพลศึกษา 1 |
| AR101 | ศิลปะ |
| TC101 | การงานอาชีพและเทคโนโลยี |

## หมวด/ฝ่าย

หมวด/ฝ่ายช่วยจัดกลุ่มวิชาตามกลุ่มสาระ ใช้สีแยกในตาราง

หมวดมาตรฐานในระบบไทย (8 กลุ่มสาระ):
- ภาษาไทย
- คณิตศาสตร์
- วิทยาศาสตร์และเทคโนโลยี
- สังคมศึกษา ศาสนาและวัฒนธรรม
- ภาษาต่างประเทศ
- สุขศึกษาและพลศึกษา
- การงานอาชีพ
- ศิลปะ

โรงเรียนนานาชาติ/EP อาจใช้:
- English / Mathematics / Science / Social Studies / Arts / PE

<Tip>
  วิชาเดียวกันที่สอนต่างระดับชั้นไม่ต้องสร้างซ้ำ — ใช้รหัสเดียวกันแล้วแยกตอนจัดตาราง
</Tip>
