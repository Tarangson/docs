หน้า **รายวิชา** เก็บข้อมูลวิชาทั้งหมดที่ใช้ในโรงเรียน — ต้องมีรายวิชาพร้อมก่อนจึงจะสามารถจัดคาบให้นักเรียนในแฟ้มตารางสอนได้

<Info>
  URL: [`app.tarangson.com/base/subjects`](https://app.tarangson.com/base/subjects)
</Info>

<img src="/images/screens/base-subjects.png" alt="หน้ารายวิชา" />

## คอลัมน์ในตาราง

| คอลัมน์ | คำอธิบาย |
| --- | --- |
| ☐ | Checkbox |
| **ลำดับ** | เลขลำดับ |
| **สี** | สีประจำวิชา — ใช้ในตารางสอน |
| **รหัสวิชา** | รหัสมาตรฐาน เช่น TH101, MA102, EN201 (ตัวอักษร+ตัวเลข) |
| **ชื่อวิชา** | เช่น "ภาษาไทยพื้นฐาน 1", "คณิตศาสตร์พื้นฐาน 2" |
| **กลุ่มสาระ** | ภาษาไทย / คณิตศาสตร์ / วิทยาศาสตร์ / สังคมศึกษา / สุขศึกษา / ศิลปะ / การงานอาชีพ / ภาษาต่างประเทศ |
| **AA** | หน่วยกิต (Academic Area weighting) |

## ฟอร์มเพิ่มรายวิชา

<Steps>
  <Step title="กด '+ เพิ่มข้อมูล'">
  </Step>
  <Step title="กรอกฟิลด์">
    - **รหัสวิชา \*** (ไม่ซ้ำ)
    - **ชื่อวิชา (ไทย) \***
    - **ชื่อวิชา (English)**
    - **กลุ่มสาระ \*** (dropdown 8 กลุ่ม)
    - **ประเภทวิชา** — พื้นฐาน / เพิ่มเติม / ชุมนุม / กิจกรรม
    - **หน่วยกิต** (decimal เช่น 0.5, 1.0, 1.5)
    - **จำนวนคาบ/สัปดาห์** — เช่น 3 คาบ = ต้องจัด 3 คาบต่อสัปดาห์
    - **ระดับชั้นที่เปิด** (multi-select — ม.1, ม.2, ฯลฯ)
    - **ต้องใช้ห้องเฉพาะ** (checkbox) — ถ้าติ๊ก จะเลือกประเภทห้องที่รองรับ
    - **สีประจำวิชา**
    - **คำอธิบายรายวิชา** (textarea)
  </Step>
  <Step title="บันทึก">
  </Step>
</Steps>

## จำนวนคาบต่อสัปดาห์

ฟิลด์สำคัญที่ **AI จัดตาราง** จะใช้ — เช่น วิชาคณิตศาสตร์พื้นฐาน 4 คาบ/สัปดาห์ หมายความว่าในแต่ละ ม.1/1 จะต้องจัดคาบวิชานี้ให้ครบ 4 คาบ (ต่างวันกัน)

<Tip>
  ถ้าวิชาต้องเรียน "ติดกัน" (เช่น แล็บ 2 คาบรวด) ใช้การตั้งค่า **คาบติดกัน** ในฟอร์มรายวิชา หรือปรับในหน้าแฟ้มตารางสอนภายหลัง
</Tip>

## สีประจำวิชา

สีวิชา**สำคัญมาก**ในตารางสอน เพราะเป็นสิ่งที่เห็นชัดที่สุดเมื่อดูตาราง — แนะนำให้กำหนดระบบสีตามกลุ่มสาระ:

| กลุ่มสาระ | สีที่แนะนำ |
| --- | --- |
| ภาษาไทย | แดง / ส้ม |
| คณิตศาสตร์ | ฟ้า / น้ำเงิน |
| วิทยาศาสตร์ | เขียว |
| สังคมศึกษา | เหลือง / น้ำตาล |
| ภาษาต่างประเทศ | ม่วง |
| ศิลปะ | ชมพู |
| สุขศึกษา | ส้มอ่อน |
| การงานอาชีพ | เทา |

## ลบรายวิชา

- ถ้ายังไม่เคยใช้ในแฟ้ม → ลบได้ปกติ
- ถ้าใช้แล้ว → ต้องเอาออกจากทุกแฟ้มก่อน
