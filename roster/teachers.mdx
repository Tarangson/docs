หน้า **ผู้สอน** คือทะเบียนครูทั้งหมดของโรงเรียน ใช้สำหรับเลือกครูผู้สอนแต่ละวิชาเมื่อสร้างตารางสอน เปิดได้จาก **Dashboard → ข้อมูลพื้นฐานตารางสอน → ผู้สอน** หรือเข้าตรงที่ `/base/teachers`

<img src="/images/screens/teachers-list.jpg" alt="หน้ารายการผู้สอน" />

## ส่วนประกอบของหน้า

### แถบเครื่องมือด้านบน

| ปุ่ม | ใช้ทำอะไร |
|---|---|
| **🔧 จัดการฟิลด์** | เพิ่ม/ลบ/แก้ไขคอลัมน์ของตาราง (เช่นเพิ่มคอลัมน์ "วิชาเอก") |
| **⬇️ แม่แบบ** | ดาวน์โหลดไฟล์ Excel เปล่าตามฟิลด์ที่กำหนดไว้ |
| **📤 นำเข้า** | อัปโหลด Excel เพื่อเพิ่มผู้สอนทีละหลายคน — ดูที่ [นำเข้าจาก Excel](/roster/excel) |
| **📥 ส่งออก** | ดาวน์โหลด Excel ของรายชื่อปัจจุบัน |
| **+ เพิ่มผู้สอน** | เปิดฟอร์มเพิ่มผู้สอนใหม่ทีละคน |

### ช่องค้นหา

ใต้แถบเครื่องมือ — กรอกรหัส ชื่อ นามสกุล หรือหมวด เพื่อกรองรายการ

### ตารางรายชื่อผู้สอน

คอลัมน์มาตรฐาน:
- **ลำดับ** — เลขลำดับ พร้อมไอคอนลากย้าย ⋮⋮
- **สี** — วงกลมสีประจำตัวครู ใช้แยกในตารางสอน
- **รหัส** — รหัสครู (เช่น T0001) เรียงได้ ↑↓
- **คำนำหน้า** — นาย / นาง / นางสาว
- **ชื่อ**
- **นามสกุล**
- **หมวด/ฝ่าย** — กลุ่มสาระ
- **คอลัมน์เพิ่มเติม** — ฟิลด์ที่ตั้งเองผ่าน "จัดการฟิลด์"

## เพิ่มผู้สอนทีละคน

กดปุ่ม **+ เพิ่มผู้สอน** มุมขวาบน — จะเปิดหน้าต่าง **เพิ่มผู้สอนใหม่**

<img src="/images/screens/teachers-add-modal.jpg" alt="หน้าต่างเพิ่มผู้สอนใหม่" />

ฟิลด์ที่ต้องกรอก:

| ช่อง | จำเป็น | ตัวอย่าง |
|---|---|---|
| **รหัสผู้สอน** | ✅ | T001 (ใส่เองหรือให้ระบบรันต่อ) |
| **คำนำหน้า** | — | เลือก นาย / นาง / นางสาว |
| **ชื่อ** | ✅ | สมชาย |
| **นามสกุล** | ✅ | ใจดี |
| **หมวด/ฝ่าย** | ✅ | เลือกจากรายการที่ตั้งไว้ |
| **ฟิลด์เพิ่มเติม** | — | ตามที่ตั้งใน "จัดการฟิลด์" |

กด **เพิ่ม** เพื่อบันทึก หรือ **ยกเลิก** เพื่อปิด

## แก้ไขข้อมูล

คลิกที่แถวของผู้สอนเพื่อแก้ไข — สามารถพิมพ์แทนที่ในช่องได้เลย ไม่มีปุ่ม "บันทึก" แยก ระบบจะบันทึกอัตโนมัติเมื่อย้าย focus

ลบครูได้โดยติ๊กช่องด้านซ้ายของแถว → ระบบจะแสดงปุ่ม **ลบ** ที่ด้านบน

## จัดเรียงและกรอง

- คลิกที่หัวคอลัมน์ที่มีลูกศร ↑↓ เพื่อเรียงข้อมูล
- คลิกที่ดินสอ ✏️ ข้างหัวคอลัมน์ "หมวด/ฝ่าย" เพื่อจัดการรายชื่อหมวดหรือฝ่าย

## เพิ่มฟิลด์เอง

กด **🔧 จัดการฟิลด์** ที่แถบบน — สามารถเพิ่มคอลัมน์ใหม่ได้ เช่น
- วิชาเอก
- ปีที่เริ่มสอน
- เบอร์โทร
- รหัสบัตรประชาชน

ฟิลด์เหล่านี้จะปรากฏทั้งในฟอร์มเพิ่มผู้สอนและในไฟล์ Excel แม่แบบ

<Warning>
  เมื่อสร้างแฟ้มจัดตารางสอนแล้ว **ไม่สามารถลบฟิลด์ใด ๆ ของผู้สอนได้** เพราะแฟ้มจะอ้างอิงโครงสร้างเดิม — ปรับโครงสร้างข้อมูลก่อนสร้างแฟ้มเสมอ
</Warning>
