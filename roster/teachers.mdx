หน้า **ผู้สอน** คือจุดรวมข้อมูลครูทั้งโรงเรียน — ต้องเพิ่มรายชื่อที่นี่ก่อนจึงจะสามารถกำหนดให้ไปสอนในแฟ้มตารางสอนได้

เข้าได้จากเมนู **ข้อมูลพื้นฐานตารางสอน > ผู้สอน**

<img src="/images/screens/base-teachers.png" alt="หน้าผู้สอน" />

## ส่วนประกอบของหน้า

หน้าประกอบด้วย 3 ส่วนหลัก — **แถบเครื่องมือด้านบน** / **ช่องค้นหา** / **ตารางข้อมูล**

### แถบเครื่องมือ (มุมขวาบน)

| ปุ่ม | ไอคอน | หน้าที่ |
| --- | --- | --- |
| **นำเข้าไฟล์** | ☁ | อัปโหลดไฟล์ Excel เพื่อเพิ่มหลายคนพร้อมกัน — ดูที่ [Import/Export Excel](/roster/excel) |
| **สลับ** | ↕ | สลับโหมดดู (ตาราง / การ์ด) |
| **นำเข้า** | ⬇ | Download template Excel สำหรับกรอกก่อนอัปโหลด |
| **ส่งออก** | ⬆ | ส่งออกข้อมูลปัจจุบันเป็น .xlsx |
| **+ เพิ่มข้อมูล** | **(สีเขียว)** | เปิด dialog เพิ่มผู้สอนทีละคน |

### ช่องค้นหา

ช่องด้านบนตาราง พิมพ์เพื่อกรองด้วย **ชื่อ, นามสกุล, รหัส** แบบทันที

### ตารางข้อมูลผู้สอน

| คอลัมน์ | คำอธิบาย |
| --- | --- |
| ☐ | Checkbox เลือกหลายแถว (สำหรับลบ/ส่งออกหลายคน) |
| **ลำดับ** | เลขลำดับ (เรียงโดยระบบ) |
| **สี** | จุดสีประจำตัวครู — ใช้ในตารางสอนเพื่อแยกครูแต่ละคน |
| **รหัส** | รหัสครู 4-5 หลัก (เช่น T0001) — ใช้ในเอกสารและนำเข้า Excel |
| **คำนำหน้า** | นาย / นาง / นางสาว / ดร. / อาจารย์ |
| **ชื่อ** | ชื่อจริง |
| **นามสกุล** | |
| **ตำแหน่งงาน** | เช่น "ครูประจำชั้น", "หัวหน้ากลุ่มสาระ" |
| **ปุ่ม ⋮** | เมนูแก้ไข / ลบ รายคน |

## วิธีเพิ่มผู้สอนทีละคน

<Steps>
  <Step title="กดปุ่ม '+ เพิ่มข้อมูล'">
    ปุ่มสีเขียวมุมขวาบน — จะเปิด dialog แบบ slide-over
  </Step>
  <Step title="กรอกข้อมูลในฟอร์ม">
    ช่องจำเป็น (มีเครื่องหมาย \*):

    - **คำนำหน้า \*** (dropdown)
    - **ชื่อ \*** / **นามสกุล \***
    - **รหัสครู \*** (ต้องไม่ซ้ำในโรงเรียน)
    - **สีประจำตัว** (palette 10 สี หรือเลือกเอง)
    - **ตำแหน่งงาน** (optional)
    - **กลุ่มสาระ** (dropdown — เช่น คณิตศาสตร์ / วิทยาศาสตร์ / ภาษาไทย)
    - **อีเมล** / **เบอร์โทร** (optional)
  </Step>
  <Step title="กดบันทึก">
    ระบบจะเพิ่มในตารางทันที ไม่ต้องรีเฟรชหน้า
  </Step>
</Steps>

## แก้ไข / ลบ

- **คลิกที่แถว** — เปิดฟอร์มแก้ไขอย่างเดียวกับตอนเพิ่ม
- **ปุ่ม ⋮** มุมขวาของแถว → **ลบ** → ยืนยัน
- **ลบหลายคน:** ติ๊ก checkbox หน้าแถว แล้วใช้ปุ่ม **"ลบที่เลือก"** ที่จะปรากฏขึ้นมา

<Warning>
  หากผู้สอนคนนั้นถูกใช้ในแฟ้มตารางสอนแล้ว **ไม่สามารถลบได้** ต้องเอาออกจากตารางก่อน
</Warning>

## นำเข้าหลายคนจาก Excel

หากโรงเรียนมีครู 50+ คน ให้ใช้วิธีนำเข้า Excel จะเร็วกว่า — ดูขั้นตอนที่ [Import/Export Excel](/roster/excel)

## คำแนะนำการตั้งรหัสและสี

- **รหัสครู:** ใช้รูปแบบเดียวกันทั้งโรงเรียน เช่น `T0001`–`T9999` เพื่อความเป็นระเบียบ
- **สีประจำตัว:** เลือกสีที่**แตกต่างกันชัดเจน**สำหรับครูในกลุ่มสาระเดียวกัน เพื่อให้แยกในตารางได้ง่าย
