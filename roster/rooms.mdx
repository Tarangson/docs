**ห้องเรียน** ในบริบทนี้หมายถึง **ห้องทางกายภาพ** ของโรงเรียน (ห้อง 111, ห้องวิทย์ 1, ห้อง Smart Classroom) ต่างจาก **ผู้เรียน** ที่เป็นห้อง "เชิงโครงสร้าง" (ม.1/1, ม.1/2)

เข้าได้จากเมนู **ข้อมูลพื้นฐานตารางสอน > ห้องเรียน**

<img src="/images/screens/base-rooms.png" alt="หน้าห้องเรียน" />

## ความแตกต่างระหว่าง "ห้องเรียน" กับ "ผู้เรียน"

| ผู้เรียน | ห้องเรียน |
| --- | --- |
| ม.1/1, ม.2/3 | ห้อง 111, ห้องวิทย์ 1 |
| กลุ่มเด็กที่เรียนด้วยกันทั้งปี | สถานที่ทางกายภาพ |
| ย้ายจากคาบหนึ่งไปอีกคาบได้ | 1 คาบ 1 ห้อง (จะจองโดยคาบเดียวกันซ้อนไม่ได้) |

<Tip>
  เช่น คาบคณิตศาสตร์ของ ม.1/1 อาจจัดที่ **ห้อง 111** ส่วนคาบวิทยาศาสตร์อาจจัดที่ **ห้องวิทย์ 1** — แต่ทั้งสองคาบเป็น**ผู้เรียน**เดียวกันคือ ม.1/1
</Tip>

## ส่วนประกอบของหน้า

แถบเครื่องมือและตารางเหมือนหน้าอื่นในกลุ่มข้อมูลพื้นฐาน (นำเข้า/ส่งออก/สลับ/+เพิ่มข้อมูล)

### คอลัมน์ในตาราง

| คอลัมน์ | คำอธิบาย |
| --- | --- |
| ☐ | Checkbox เลือกหลายแถว |
| **ลำดับ** | เลขเรียง |
| **สี** | สีประจำห้อง |
| **รหัส** | รหัสห้อง (เช่น 111, 112, 113) |
| **ห้องที่** | ชื่อเต็ม (เช่น "ห้องเรียนบรรยาย") |
| **ประเภท** | ห้องเรียนบรรยาย / ห้องปฏิบัติการ / ห้องคอมพิวเตอร์ / ห้องศิลปะ / โรงยิม / Smart Classroom / อื่น ๆ |
| **หมวดหมู่** | เช่น วิทยาศาสตร์, ภาษา, กีฬา |
| **ADB** | สัญลักษณ์ adjacent building (ใช้เมื่อโรงเรียนมีหลายอาคาร) |
| **ปุ่ม ⋮** | แก้ไข / ลบ |

## วิธีเพิ่มห้อง

<Steps>
  <Step title="กด '+ เพิ่มข้อมูล'">
  </Step>
  <Step title="กรอกข้อมูล">
    - **รหัสห้อง \*** — มักใช้เลขตามชั้น+เลขห้อง เช่น 111 = อาคาร 1 ชั้น 1 ห้อง 1
    - **ชื่อห้อง \*** — ชื่อที่จะแสดงในตาราง เช่น "ห้องฟิสิกส์ 1"
    - **ประเภทห้อง \*** — dropdown
    - **หมวดวิชาที่รองรับ** — หลาย option
    - **จำนวนที่นั่ง**
    - **อุปกรณ์พิเศษ** — textarea (โปรเจคเตอร์, กระดานอัจฉริยะ, ฯลฯ)
    - **สีประจำห้อง**
  </Step>
  <Step title="บันทึก">
    ห้องจะถูกเพิ่มเข้าในรายการสำหรับให้เลือกในแฟ้มตารางสอน
  </Step>
</Steps>

## กฎการจอง

- **1 คาบ 1 ห้อง 1 วิชา** — ระบบจะไม่ยอมให้ 2 วิชาใช้ห้องเดียวกันในคาบเดียวกัน (ตรวจจับอัตโนมัติ)
- **ห้องเฉพาะทาง:** ถ้าระบุ "หมวดวิชาที่รองรับ" ไว้แล้ว AI จะพยายามจัดวิชานั้น ๆ ให้ลงห้องที่เหมาะสมก่อน

## จัดกลุ่มห้องด้วย "หมวดหมู่"

สำหรับโรงเรียนใหญ่ที่มีห้องเป็นร้อย ๆ ห้อง ใช้ฟิลด์ **หมวดหมู่** เพื่อจัดกลุ่ม (เช่น "อาคาร 1", "อาคารวิทย์") จะช่วยให้กรองและเรียกดูได้เร็วขึ้น
