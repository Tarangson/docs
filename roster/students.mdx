หน้า **ผู้เรียน** คือทะเบียนกลุ่มผู้เรียน เช่น ม.1/1, ม.1/2 — ไม่ใช่นักเรียนรายบุคคล แต่เป็น **กลุ่ม/ห้อง** ที่ใช้เรียกในตารางสอน

เปิดได้จาก **Dashboard → ข้อมูลพื้นฐานตารางสอน → ผู้เรียน** หรือเข้าตรงที่ `/base/students`

## ส่วนประกอบของหน้า

### แถบเครื่องมือด้านบน

| ปุ่ม | ใช้ทำอะไร |
|---|---|
| **🔧 จัดการฟิลด์** | เพิ่ม/ลบ/แก้ไขคอลัมน์ของตาราง |
| **⬇️ แม่แบบ** | ดาวน์โหลด Excel เปล่าตามฟิลด์ที่ตั้ง |
| **📤 นำเข้า** | อัปโหลด Excel เพิ่มกลุ่มผู้เรียนทีละหลายรายการ |
| **📥 ส่งออก** | ดาวน์โหลด Excel ของรายชื่อปัจจุบัน |
| **+ เพิ่มนักเรียน** | เปิดฟอร์มเพิ่มกลุ่มผู้เรียนใหม่ |

### ตารางรายการ

คอลัมน์มาตรฐาน:
- **ลำดับ** — เลขลำดับและไอคอนลากย้าย
- **สี** — สีประจำกลุ่มผู้เรียน
- **รหัส** — รหัสกลุ่ม (เช่น ม.1/1)
- **ชื่อชั้น** — รหัสภายใน (เช่น STU000001)
- **ระดับชั้น** — เช่น ม.1, ม.2, ป.5
- **ตึก** — ตึกที่ห้องประจำตั้งอยู่
- **คอลัมน์เพิ่มเติม** — ตามที่ตั้งใน "จัดการฟิลด์"

## เพิ่มกลุ่มผู้เรียน

กด **+ เพิ่มนักเรียน** มุมขวาบน — ฟอร์มจะมีฟิลด์มาตรฐาน:

- **รหัสห้อง** เช่น ม.1/1
- **ชื่อชั้น/รหัสภายใน** เช่น STU000001
- **ระดับชั้น** เช่น ม.1
- **ตึก** (ถ้ามี)

กด **เพิ่ม** เพื่อบันทึก

## เคล็ดลับการตั้งชื่อ

| รหัส | ใช้ได้ | หมายเหตุ |
|---|---|---|
| ม.1/1 | ✅ | รูปแบบมาตรฐาน |
| ป.6 | ✅ | ห้องเดียวต่อชั้น |
| EP-1A | ✅ | English Program |
| Year 7B | ✅ | นานาชาติ |

ตั้งให้สั้น เพราะรหัสนี้จะปรากฏในช่องเล็ก ๆ ในตารางสอน

## แก้ไขและลบ

- คลิกที่แถวเพื่อแก้ไขในที่ — บันทึกอัตโนมัติเมื่อย้าย focus
- ติ๊กช่องซ้ายของแถวเพื่อแสดงปุ่มลบ

## จำนวนกลุ่มที่ควรมี

| ระดับโรงเรียน | จำนวนกลุ่ม |
|---|---|
| ประถมเล็ก | ~6 (ป.1-ป.6) |
| ประถมใหญ่ | ~12-30 (มีหลายห้องต่อชั้น) |
| มัธยมต้น | ~6-30 (ม.1-ม.3 × หลายห้อง) |
| มัธยมปลาย | ~9-45 (ม.4-ม.6 × แผนการเรียน × หลายห้อง) |
| มัธยมรวม | 30-90 |
