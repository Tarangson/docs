ในบริบทของ ตารางสอน คำว่า **"ผู้เรียน"** หมายถึง **ห้องเรียน** (เช่น ม.1/1, ม.4/3) ไม่ใช่รายชื่อเด็กรายคน — เพราะตารางสอนจัดกันเป็นหน่วยห้อง

เข้าได้จากเมนู **ข้อมูลพื้นฐานตารางสอน > ผู้เรียน**

<img src="/images/screens/base-students.png" alt="หน้าผู้เรียน" />

## ส่วนประกอบของหน้า

หน้ามีแถบเครื่องมือและตารางแบบเดียวกับหน้า [ผู้สอน](/roster/teachers) คือ:

| ปุ่ม | หน้าที่ |
| --- | --- |
| **นำเข้าไฟล์** | อัปโหลด Excel |
| **สลับ** | สลับโหมดดู |
| **นำเข้า** | Download template Excel |
| **ส่งออก** | Export เป็น .xlsx |
| **+ เพิ่มข้อมูล** | เปิดฟอร์มเพิ่มห้องเรียน |

### คอลัมน์ในตาราง

| คอลัมน์ | คำอธิบาย |
| --- | --- |
| ☐ | Checkbox เลือกหลายแถว |
| **ลำดับ** | เลขเรียง |
| **สี** | สีประจำห้อง — แยกแต่ละชั้น/สาย |
| **ห้อง** | ชื่อเรียก เช่น ม.1/1, ม.1/2, ม.1/3 |
| **รหัส** | รหัสห้อง (เช่น ST000001) |
| **ระดับชั้น** | ม.1 / ม.2 / ม.3 / ม.4 / ม.5 / ม.6 / ป.1 ... |
| **สูตร** | สูตรแผนการเรียน เช่น ศิลป์-ภาษา, วิทย์-คณิต (เฉพาะ ม.ปลาย) |
| **จำนวน** | จำนวนเด็กในห้อง (ใช้ในเอกสาร) |
| **ปุ่ม ⋮** | แก้ไข / ลบ |

## วิธีเพิ่มห้องเรียน

<Steps>
  <Step title="กด '+ เพิ่มข้อมูล'">
    ปุ่มสีเขียวมุมขวาบน
  </Step>
  <Step title="กรอกข้อมูลห้อง">
    - **ชื่อห้อง \*** (เช่น ม.1/1)
    - **รหัสห้อง \*** (ต้องไม่ซ้ำ)
    - **ระดับชั้น \*** (dropdown)
    - **แผนการเรียน** (dropdown — เช่น วิทย์-คณิต, ศิลป์-ภาษา)
    - **จำนวนนักเรียน**
    - **ครูประจำชั้น** (dropdown จากรายชื่อใน [ผู้สอน](/roster/teachers))
    - **สีประจำห้อง**
  </Step>
  <Step title="บันทึก">
    ห้องที่เพิ่มจะไปปรากฏในทุกฟอร์มที่ต้องเลือก "ผู้เรียน" ของแฟ้มตารางสอน
  </Step>
</Steps>

## เคล็ดลับการจัดกลุ่มห้อง

- **ตั้งชื่อเรียงตามลำดับ:** ม.1/1, ม.1/2, ... — ระบบจะเรียง lexicographic ให้อัตโนมัติ
- **ใช้สีแยกระดับ:** เช่น ม.1 สีฟ้า, ม.2 สีเขียว, ม.3 สีส้ม — ทำให้ดูตารางรวมได้ง่าย
- **ใส่ครูประจำชั้นให้ครบ** เพื่อใช้ในรายงานและเอกสารพิมพ์

## ลบห้อง

ห้องที่เคยถูกใช้ในแฟ้มตารางสอนใดก็ตาม **ไม่สามารถลบได้** — ต้องย้ายออกจากแฟ้มทั้งหมดก่อน

## นำเข้าจำนวนมาก

โรงเรียนขนาดกลาง-ใหญ่ (50+ ห้อง) ใช้วิธี [Import Excel](/roster/excel) จะประหยัดเวลามาก
