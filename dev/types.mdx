ไฟล์ `app/lib/types.ts` เก็บ type definitions ทั้งหมดที่ใช้ร่วมกันทั่วทั้งแอป แบ่งเป็น 3 หมวดหมู่:

1. **Academic Defaults** -- ประเภทข้อมูลพื้นฐานทางวิชาการ
2. **Timetable File** -- ประเภทข้อมูลไฟล์ตารางสอน
3. **Wizard Templates** -- ประเภทข้อมูล template สำหรับระบบ wizard

---

## Academic Defaults Types

### `DayOfWeek`

```typescript
type DayOfWeek = "MON" | "TUE" | "WED" | "THU" | "FRI" | "SAT" | "SUN";
```

Union type สำหรับวันในสัปดาห์ ใช้เป็น key ใน schedule (`"MON_1"`, `"TUE_3"`)

### `PeriodTime`

```typescript
interface PeriodTime {
  start: string; // "HH:mm" เช่น "08:30"
  end: string;   // "HH:mm" เช่น "09:20"
}
```

### `PeriodGenSettings`

```typescript
interface PeriodGenSettings {
  periodDuration: number; // นาทีต่อคาบ (เช่น 50)
  breakDuration: number;  // นาทีพักระหว่างคาบ (เช่น 10)
}
```

Helper สำหรับ auto-generate เวลาคาบเรียน

### `CustomFieldDef`

```typescript
interface CustomFieldDef {
  id: string;
  label: string;
  type: "text" | "number" | "select";
  options?: string[]; // สำหรับ type "select"
}
```

คำจำกัดความของ custom field ที่โรงเรียนสามารถสร้างเพิ่มเองได้ เก็บใน `_settings` document ของแต่ละ entity collection

```typescript
interface TimetableFileCreatedBy {

```

### `TimetableFileProfile`

```typescript
interface TimetableFileProfile {

  updatedAt?: string;

```

### `RosterAcademic`

```typescript
interface RosterAcademic {
  timezone: string;
  days: DayOfWeek[];
  periodCount: number;
  periods: Record<string, PeriodTime>;
  periodCall?: string;
}
```

Snapshot ของ academic settings ที่ใช้กับไฟล์ตารางสอนนั้นๆ

### `ScheduleEntry`

```typescript
interface ScheduleEntry {
  id: string;
  dayOfWeek: DayOfWeek;
  periodKey: string;
  teacherId: string;
  subjectId: string;
  studentId: string;
  roomId: string;
  specialPeriods?: SpecialPeriodsInfo | string;
  isPin?: boolean;
}
```

ตัวแทนข้อมูล schedule entry ที่ใช้ในฝั่ง client สำหรับ CRUD operations

### `TimeslotData`

```typescript
interface TimeslotData {
  subjectId: string;
  teacherId?: string;
  studentId?: string;
  roomId?: string;
  specialPeriods?: SpecialPeriodsInfo | string;
  isPin?: boolean;
}
```

<Callout type="info">
  `TimeslotData` คือ shape ที่เก็บจริงใน Firestore (doc ID = `"MON_1"`) ส่วน `ScheduleEntry` เป็น enriched version ที่ใช้ในฝั่ง client
</Callout>

### `SpecialPeriodsInfo`

```typescript
interface SpecialPeriodsInfo {
  id: string;    // group ID เช่น "sp_l3x2k4_abc123"
  type: string;  // "wizard" | "multiTeacher" | "multiStudent" | "multiRoom" | ...
}
```

ใช้สำหรับ mark ว่า timeslot นี้เป็นคาบพิเศษ (wizard mode) รองรับ backward compatibility กับ format เดิมที่เป็น string

## Wizard Template Types

### `WizardConfigMode`

```typescript
type WizardConfigMode = "none" | "single" | "multi";
```

กำหนดว่า entity type นั้นเลือกได้กี่ตัว:
- `"none"` -- ไม่ใช้
- `"single"` -- เลือก 1 ตัว
- `"multi"` -- เลือกหลายตัว

### `WizardConfig`

```typescript
type WizardConfig = {
  teacherMode: WizardConfigMode;
  studentMode: WizardConfigMode;
  roomMode: WizardConfigMode;
};
```

### `WizardTemplate`

```typescript
interface WizardTemplate {
  id: string;
  label: string;
  description: string;
  config: WizardConfig;
}
```

## Helper Functions

### `generateId(prefix)`

```typescript
function generateId(prefix: string): string {
  return `${prefix}_${Date.now().toString(36)}_${Math.random().toString(36).slice(2, 8)}`;
}
```

สร้าง unique ID จาก timestamp + random string ใช้ prefix ต่างกันตาม entity type:
- `"t"` -- teacher
- `"st"` -- student
- `"r"` -- room
- `"sub"` -- subject
- `"sp"` -- special periods

### `getSpecialPeriodsType(sp)`

```typescript
function getSpecialPeriodsType(
  sp: SpecialPeriodsInfo | string | undefined
): string | undefined
```

ดึง `type` จาก `specialPeriods` field รองรับทั้ง format เก่า (string) และ format ใหม่ (object)

### `isWizardType(sp)`

```typescript
function isWizardType(
  sp: SpecialPeriodsInfo | string | undefined
): boolean
```

ตรวจสอบว่า specialPeriods เป็นแบบ wizard หรือไม่ (backward-compatible)

### `isSpecialType(sp)`

```typescript
function isSpecialType(
  sp: SpecialPeriodsInfo | string | undefined
): boolean
```

ตรวจสอบว่ามี specialPeriods หรือไม่ (truthy check แบบ backward-compatible)
