## Prerequisites

ก่อนเริ่มพัฒนา ต้องติดตั้ง:

- **Node.js** 18+ (แนะนำ v20 LTS หรือใหม่กว่า)
- **npm** (มาพร้อม Node.js)
- **Git**
- Firebase project (สำหรับ Auth + Firestore + Storage)

## ขั้นตอนการติดตั้ง

<Steps>
  <Step title="Clone repository">
    ```bash
    git clone https://github.com/your-org/tarangson-webapp.git
    cd tarangson-webapp
    ```
  </Step>

  <Step title="Install dependencies">
    ```bash
    npm install
    ```

    Dependencies หลักที่จะถูกติดตั้ง:
    - `next@16.1.6`, `react@19.2.3`, `react-dom@19.2.3`
    - `firebase@^12.9.0`
    - `@dnd-kit/core`, `@dnd-kit/sortable`, `@dnd-kit/modifiers`
    - `xlsx@^0.18.5`
    - `radix-ui@^1.4.3`, `lucide-react`, `sonner`
    - `tailwindcss@^4`, `tailwind-merge`, `clsx`
  </Step>

  <Step title="ตั้งค่า Firebase project">
    1. ไปที่ [Firebase Console](https://console.firebase.google.com)
    2. สร้างโปรเจกต์ใหม่ หรือเลือกโปรเจกต์ที่มีอยู่
    3. เปิดใช้งาน services ต่อไปนี้:
       - **Authentication** -- เปิด Email/Password และ Google sign-in provider
       - **Firestore Database** -- สร้าง database ชื่อ `tarangson` (named database)
       - **Storage** -- สำหรับเก็บ logo โรงเรียน
    4. ไปที่ Project Settings > General > Your apps > เพิ่ม Web app
    5. คัดลอก Firebase config values
  </Step>

  <Step title="สร้างไฟล์ .env.local">
    สร้างไฟล์ `.env.local` ที่ root ของโปรเจกต์:

    ```bash
    # Firebase Configuration
    NEXT_PUBLIC_FIREBASE_API_KEY=your-api-key
    NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your-project.firebaseapp.com
    NEXT_PUBLIC_FIREBASE_PROJECT_ID=your-project-id
    NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your-project.firebasestorage.app
    NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your-sender-id
    NEXT_PUBLIC_FIREBASE_APP_ID=your-app-id
    NEXT_PUBLIC_FIREBASE_MEASUREMENT_ID=G-XXXXXXXXXX
    ```

    <Callout type="warning">
      Firestore ใช้ **named database** ชื่อ `"tarangson"` ไม่ใช่ default database -- ต้องสร้าง named database ใน Firebase Console ก่อน
    </Callout>
  </Step>

  <Step title="Run development server">
    ```bash
    npm run dev
    ```

    เปิด [http://localhost:3000](http://localhost:3000) ในเบราว์เซอร์
  </Step>
</Steps>

## Scripts ที่ใช้ได้

```json
{
  "scripts": {
    "dev": "next dev",
    "build": "next build",
    "start": "next start",
    "lint": "eslint"
  }
}
```

| Script | คำสั่ง | คำอธิบาย |
|---|---|---|
| `dev` | `npm run dev` | เริ่ม dev server พร้อม hot reload |
| `build` | `npm run build` | Build สำหรับ production |
| `start` | `npm run start` | รัน production server (ต้อง build ก่อน) |
| `lint` | `npm run lint` | ตรวจสอบ code ด้วย ESLint |

## Firebase Configuration Priority

ไฟล์ `app/lib/firebase.ts` มีลำดับการอ่าน config ดังนี้:

1. **`FIREBASE_WEBAPP_CONFIG`** หรือ **`NEXT_PUBLIC_FIREBASE_WEBAPP_CONFIG`** -- JSON string (ใช้กับ Firebase App Hosting)
2. **Environment variables แยกตัว** -- `NEXT_PUBLIC_FIREBASE_API_KEY`, `NEXT_PUBLIC_FIREBASE_PROJECT_ID`, ฯลฯ (ใช้กับ `.env.local`)

```typescript
// ตัวอย่างจาก firebase.ts
const firebaseConfig = getFirebaseConfig();

let app: FirebaseApp | null = null;
let auth: Auth | null = null;
let db: Firestore | null = null;
let storage: FirebaseStorage | null = null;

if (firebaseConfig.apiKey) {
  app = getApps().length === 0 ? initializeApp(firebaseConfig) : getApps()[0];
  auth = getAuth(app);
  db = getFirestore(app, "tarangson"); // Named database
  storage = getStorage(app);
}
```

<Callout type="info">
  Firebase App Hosting จะ inject `FIREBASE_WEBAPP_CONFIG` เป็น JSON string อัตโนมัติ สำหรับ local development ใช้ `.env.local` แทน
</Callout>

## Build for Production

```bash
npm run build
```

Next.js จะ build static pages และ server-side rendering ไว้ใน `.next/` directory

สำหรับ deploy ไปยัง Firebase App Hosting:

```bash
firebase deploy --only hosting
```

## โครงสร้างไฟล์สำคัญ

| ไฟล์ | หน้าที่ |
|---|---|
| `app/layout.tsx` | Root layout -- wrap ด้วย `AuthProvider`, Kanit font, `Toaster` |
| `app/lib/firebase.ts` | Firebase initialization (app, auth, db, storage) |
| `app/lib/firestore.ts` | Firestore utility functions ทั้งหมด |
| `app/lib/types.ts` | TypeScript types, interfaces, constants |
| `app/lib/excel.ts` | Excel import/export functions |
| `app/context/AuthContext.tsx` | Auth state management |
| `app/components/ProtectedRoute.tsx` | Route guard component |
