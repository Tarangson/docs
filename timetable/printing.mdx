หน้า **พิมพ์** คือส่วนส่งออกเอกสารของ Tarangson — รองรับการพิมพ์ตารางสอน ตารางเรียน ตารางห้อง และรายชื่อต่าง ๆ เป็น PDF หรือพิมพ์ตรงออกเครื่องพิมพ์

<Info>
  URL: [`app.tarangson.com/print`](https://app.tarangson.com/print) — เข้าได้จาก Dashboard → การ์ด **"พิมพ์"**
</Info>

## ขั้นตอนแรก — เลือกแฟ้ม

<img src="/images/screens/print.png" alt="หน้าพิมพ์ — เลือกแฟ้มก่อนเริ่ม" />

ครั้งแรกที่เปิดหน้านี้ จะมี dialog **"เลือกแฟ้มงาน"** ขึ้นให้เลือกจากแฟ้มที่มี (เช่น "เทอม 1 / 2569", "เทอม 2 / 2569") — คลิกเพื่อเลือก

## โครงสร้างหน้าพิมพ์

<img src="/images/screens/print-selected.png" alt="หน้าพิมพ์หลังเลือกแฟ้ม" />

หน้าแบ่งเป็น 3 คอลัมน์:

### 1. Sidebar ซ้าย — เลือกรายงาน

แสดงแฟ้มที่เลือกอยู่ด้านบนสุด (เช่น "เทอม 1 / 2569" พร้อมไอคอน) แล้วมีหมวดรายงาน 2 กลุ่ม:

**รายงานตารางสอน**
- **ตารางสอน** — ตารางของครูแต่ละคน
- **ตารางเรียน** — ตารางของห้องเรียน (ม.1/1, ...)
- **ตารางห้องเรียน** — ตารางของห้องกายภาพ (111, 112, ...)

**รายงานรายชื่อ**
- **รายชื่อผู้สอน** — รายการครูในแฟ้ม
- **รายชื่อผู้เรียน** — รายการห้องเรียนและจำนวนนักเรียน
- **รายชื่อห้องเรียน** — รายการห้องกายภาพ

คลิกรายงานที่ต้องการ — หัวข้อจะแสดงด้านขวา

### 2. คอลัมน์กลาง — ตั้งค่ารายงาน

| ส่วน | รายละเอียด |
| --- | --- |
| **ดัชนี / ตัวอย่าง** (tab) | สลับระหว่างการตั้งค่าและการดู preview |
| **รูปแบบตาราง** | dropdown เลือกรูปแบบตาราง (grid / list / compact) — มี preview เล็ก ๆ |
| **รูปแบบเพิ่มเติม** | checkboxes เช่น "แสดงสีพื้น", "แสดงรหัสวิชา", "แสดงห้อง" |
| **ลักษณะการพิมพ์** | A4 แนวตั้ง / A4 แนวนอน / A3 |
| **หัว/ท้ายกระดาษ** | เปิด-ปิด logo, ชื่อโรงเรียน, เลขหน้า, วันที่พิมพ์ |
| **จำนวนรายการต่อหน้า** | 1 / 2 / 4 ต่อ 1 หน้า |

### 3. คอลัมน์ขวา — พื้นที่ Preview

- เมื่อยังไม่กดดูตัวอย่าง: แสดงไอคอนเครื่องพิมพ์ + ข้อความ **"เลือกรายงานและกด 'ดูตัวอย่าง' เพื่อแสดง PDF"**
- หลังกด: แสดง PDF preview เต็มขนาด — สามารถเลื่อน, ซูม, ดาวน์โหลด

## ขั้นตอนการพิมพ์ทีละขั้น

<Steps>
  <Step title="เลือกแฟ้มงาน">
    Dialog ขึ้นอัตโนมัติตอนเข้าหน้า — หรือกดปุ่มเปลี่ยนแฟ้มที่มุมซ้ายบน
  </Step>
  <Step title="เลือกประเภทรายงาน">
    เช่น "ตารางสอน" จาก sidebar ซ้าย
  </Step>
  <Step title="กรองหรือเลือกรายการ">
    หากเป็นตารางสอน → เลือกว่าพิมพ์**ครูคนเดียว** หรือ**ทุกคน** พร้อมกัน
  </Step>
  <Step title="ตั้งค่ารูปแบบ">
    - เลือกรูปแบบตาราง
    - ติ๊ก checkbox รายละเอียดที่ต้องการ
    - เลือกขนาดกระดาษ
  </Step>
  <Step title="กด 'ดูตัวอย่าง'">
    PDF preview จะแสดงในคอลัมน์ขวา — ตรวจสอบให้ชัดเจน
  </Step>
  <Step title="ดาวน์โหลด / พิมพ์">
    - กด **"ดาวน์โหลด PDF"** เพื่อ save ไฟล์
    - หรือกด **"พิมพ์"** เพื่อส่งไปเครื่องพิมพ์ทันที (เปิด dialog พิมพ์ของเบราว์เซอร์)
  </Step>
</Steps>

## รูปแบบที่รองรับ (7 แบบ)

| # | ชื่อ | ใช้เมื่อไหร่ |
| --- | --- | --- |
| 1 | **Grid มาตรฐาน** | ใช้ติดบอร์ด แจกครู |
| 2 | **Grid Compact** | เมื่อพื้นที่จำกัด |
| 3 | **List Format** | รายการแนวตั้งพิมพ์ติดห้อง |
| 4 | **ครู 1 คน / 1 หน้า** | แจกครูแต่ละคน |
| 5 | **ห้อง 1 ห้อง / 1 หน้า** | แจกนักเรียน |
| 6 | **รวมหลายห้อง / 1 หน้า** | ประหยัดกระดาษ |
| 7 | **รายงานสรุปสถิติ** | รวมจำนวนคาบและเปอร์เซ็นต์ |

## พิมพ์ทั้งโรงเรียนในครั้งเดียว

เลือกรายงาน "ตารางสอน" → เลือก "ครูทั้งหมด" → กดดูตัวอย่าง → ดาวน์โหลด PDF — จะได้ไฟล์เดียวที่มีตารางครูทุกคน เรียงตามรหัสหรือชื่อ (เลือกได้)

## เคล็ดลับ

<Tip>
  - **ตรวจตารางก่อนพิมพ์** — เปิดเมนูข้อขัดแย้งใน Editor ให้แน่ใจว่าไม่มี conflict แดงค้างอยู่
  - **พิมพ์เป็น PDF ก่อน** แล้วค่อยส่งเครื่องพิมพ์จริง ประหยัดกระดาษ
  - **ตั้งค่าหัวกระดาษล่วงหน้า** โดยกรอกชื่อและ logo โรงเรียนใน [ข้อมูลโรงเรียน](/settings/school-profile)
</Tip>
