## ภาพรวม

หน้าจัดการแฟ้มงาน (`/timetable/files`) เป็นศูนย์กลางสำหรับดูและจัดการแฟ้มจัดตารางสอนทั้งหมดของโรงเรียน คุณสามารถดูรายการแฟ้ม สร้างแฟ้มใหม่ เปิดจัดการข้อมูลในแฟ้ม หรือลบแฟ้มที่ไม่ต้องการ

## หน้าแสดงรายการแฟ้มงาน

หน้ารายการแฟ้มงานแสดงข้อมูลเป็นตาราง ประกอบด้วยคอลัมน์:

| คอลัมน์ | คำอธิบาย |
|---|---|
| **#** | ลำดับที่ |
| **ชื่อแฟ้มงาน** | ชื่อแฟ้มและรายละเอียด (ถ้ามี) |
| **สร้างโดย** | ชื่อหรืออีเมลผู้สร้างแฟ้ม |
| **วันที่สร้าง** | วันและเวลาที่สร้างแฟ้ม |
| **แก้ไขล่าสุด** | วันและเวลาที่แก้ไขล่าสุด |
| **จัดการ** | ปุ่มเข้าสู่หน้าจัดการข้อมูลในแฟ้ม |
| **ลบ** | ปุ่มลบแฟ้มงาน |

## การค้นหาแฟ้มงาน

ใช้ช่องค้นหาที่ด้านบนของตารางเพื่อค้นหาแฟ้มงาน คุณสามารถค้นหาด้วย:

- **ชื่อแฟ้มงาน**
- **รายละเอียด**
- **ชื่อผู้สร้าง**
- **อีเมลผู้สร้าง**

คลิกปุ่ม **X** ที่ช่องค้นหาเพื่อล้างคำค้นหา

## การแบ่งหน้า (Pagination)

เมื่อมีแฟ้มงานจำนวนมาก ระบบจะแบ่งแสดงเป็นหน้า คุณสามารถ:

- เลือกจำนวนแถวต่อหน้า: **10**, **25**, **50** หรือ **100** แถว
- ใช้ปุ่มลูกศรซ้าย/ขวาเพื่อเลื่อนหน้า
- ดูตำแหน่งปัจจุบัน เช่น "แสดง 1-25 จาก 42"

## การสร้างแฟ้มใหม่

คลิกปุ่ม **สร้างแฟ้มใหม่** ที่มุมขวาบน ระบบจะนำคุณไปหน้าสร้างแฟ้มงานใหม่ (`/timetable/new`)

## การจัดการข้อมูลในแฟ้ม

คลิกไอคอน **จัดการ** (Database) ในแถวของแฟ้มที่ต้องการ ระบบจะนำคุณไปหน้าจัดการข้อมูลในแฟ้ม (`/timetable/files/{fileId}/manage`) ซึ่งมีฟีเจอร์:

<Tabs>
  <Tab title="ผู้สอน">
    ดูและแก้ไขรายชื่อผู้สอนในแฟ้ม ข้อมูลประกอบด้วย:
    - **รหัส** (code)
    - **คำนำหน้า** (prefix) — เลือกจากรายการที่ตั้งค่าไว้
    - **ชื่อ** (firstName) — ฟิลด์บังคับ
    - **นามสกุล** (lastName)
    - **กลุ่มสาระ** (department) — เลือกจากรายการที่ตั้งค่าไว้
    - Custom field ที่เพิ่มเติม
  </Tab>

  <Tab title="ผู้เรียน">
    ดูและแก้ไขรายชื่อผู้เรียนในแฟ้ม ข้อมูลประกอบด้วย:
    - **รหัส** (code)
    - **ชั้น/ห้อง** (className) — ฟิลด์บังคับ
    - **ระดับชั้น** (gradeGroup) — เลือกจากรายการที่ตั้งค่าไว้
    - Custom field ที่เพิ่มเติม
  </Tab>

  <Tab title="ห้องเรียน">
    ดูและแก้ไขรายชื่อห้องเรียนในแฟ้ม ข้อมูลประกอบด้วย:
    - **รหัส** (code)
    - **ชื่อห้อง** (name) — ฟิลด์บังคับ
    - **รายละเอียด** (description)
    - Custom field ที่เพิ่มเติม
  </Tab>

  <Tab title="วิชาเรียน">
    ดูและแก้ไขรายชื่อวิชาเรียนในแฟ้ม ข้อมูลประกอบด้วย:
    - **รหัสวิชา** (code) — ฟิลด์บังคับ
    - **ชื่อวิชา** (name) — ฟิลด์บังคับ
  </Tab>
</Tabs>

### ฟีเจอร์ในหน้าจัดการข้อมูล

- **เพิ่มรายการ** — คลิกปุ่มเพิ่ม (เช่น **เพิ่มผู้สอน**) จะเปิด dialog กรอกข้อมูล
- **แก้ไข** — คลิกไอคอนแก้ไข (ดินสอ) ในแถวที่ต้องการ
- **ค้นหา** — พิมพ์ค้นหาจากฟิลด์ต่าง ๆ ของแต่ละประเภท
- **เรียงลำดับ** — คลิกที่หัวคอลัมน์เพื่อเรียงจาก ก-ฮ หรือ ฮ-ก
- **แบ่งหน้า** — เลือกจำนวนรายการต่อหน้า (10, 20 หรือ 50)
- **สถานะตารางสอน** — ไอคอนปฏิทินสีเขียวแสดงว่ารายการนั้นมีข้อมูลตารางสอนอยู่แล้ว (ยกเว้นแท็บวิชาเรียน)

## การลบแฟ้มงาน

<Steps>
  <Step title="คลิกปุ่มลบ">
    คลิกไอคอน **ลบ** (ถังขยะ) ในแถวของแฟ้มที่ต้องการลบ
  </Step>

  <Step title="ยืนยันการลบ">
    ระบบจะแสดง dialog ยืนยัน โดยแจ้งชื่อแฟ้มที่จะลบ คลิก **ลบแฟ้มงาน** เพื่อยืนยัน หรือ **ยกเลิก** เพื่อกลับ
  </Step>
</Steps>

<Callout type="warning">
  เมื่อลบแฟ้มงาน ข้อมูลทั้งหมดในแฟ้มจะถูกลบอย่างถาวร รวมถึง:
  - ตารางสอนทั้งหมด
  - รายชื่อครูผู้สอน
  - รายชื่อนักเรียน
  - รายชื่อห้องเรียน
  - รายชื่อวิชาเรียน

  การดำเนินการนี้ **ไม่สามารถย้อนกลับได้**
</Callout>

## การสลับระหว่างแฟ้มงาน

เมื่อคุณอยู่ในหน้าจัดตารางสอนหรือหน้าดูตารางสอน คุณสามารถสลับแฟ้มงานได้ 2 วิธี:

1. **จากหน้าจัดการแฟ้มงาน** — กลับมาหน้านี้แล้วเลือกเปิดแฟ้มที่ต้องการ
2. **จาก dialog เลือกแฟ้ม** — ในหน้าจัดตาราง/ดูตาราง ระบบจะให้เลือกแฟ้มงานเมื่อเข้าหน้า หรือคุณสามารถเปลี่ยนแฟ้มผ่าน dropdown ในส่วนหัว
