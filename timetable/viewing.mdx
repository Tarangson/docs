โหมด **ดูตาราง** ทำให้ทุกคนในโรงเรียน (ครู หรือนักเรียน) เปิดดูตารางของตัวเองได้**โดยไม่แก้ไขข้อมูล** — ใช้ link แชร์ได้ เข้าจาก Dashboard หรือเมนูแยกต่างหาก

<Info>
  เข้าถึงได้จาก Dashboard → การ์ด **"ดูตาราง"** หรือ URL โดยตรง `/view/...`
</Info>

## 3 มุมมองของ "ดูตาราง"

### 1. ตารางสอนของครู

ดูตารางของครูคนหนึ่ง — ว่าต้องสอนอะไร วันไหน คาบไหน ที่ห้องใด

**กลุ่มเป้าหมาย:** ครู และหัวหน้ากลุ่มสาระ

**ส่วนประกอบ:**
- Dropdown เลือกครู (หรือพิมพ์ชื่อค้นหา)
- ตาราง 5-7 วัน × 8 คาบ แสดงชื่อวิชา, ห้องที่สอน, ห้องเรียนผู้เรียน
- สรุปจำนวนคาบรวมต่อสัปดาห์

### 2. ตารางเรียนของห้องเรียน

ดูตารางของห้องนักเรียน (เช่น ม.1/1) — นักเรียนเปิดดูเพื่อรู้ว่าแต่ละคาบเรียนวิชาอะไร กับครูคนใด ที่ห้องใด

**กลุ่มเป้าหมาย:** นักเรียน และครูประจำชั้น

**ส่วนประกอบ:**
- Dropdown เลือกห้อง (ม.1/1, ม.2/3, ฯลฯ)
- ตารางแสดง วิชา, ครู, ห้องกายภาพ
- สี = สีประจำวิชา

### 3. ตารางห้อง (ห้องกายภาพ)

ดูการใช้งานห้อง 111 ตลอดสัปดาห์ — ว่าคาบไหนว่าง คาบไหนมีคลาส

**กลุ่มเป้าหมาย:** เจ้าหน้าที่ห้อง, ภารโรง, ผู้ดูแลอาคาร

**ส่วนประกอบ:**
- Dropdown เลือกห้อง
- ตารางแสดง วิชา + ครู + ผู้เรียน ในแต่ละคาบ

## โหมดการแสดงผล

แต่ละมุมมองมี **2 โหมด**:

### Card Mode

แสดงคาบเป็นการ์ดสี — อ่านง่าย เหมาะกับมือถือและการแชร์ภาพ

### Table Mode

ตาราง classic สำหรับ print หรือใช้ในเอกสาร

## ปุ่มและตัวเลือก

| ปุ่ม | หน้าที่ |
| --- | --- |
| **เลือกแฟ้ม** | เลือกว่าดูแฟ้มของภาคเรียนใด (เทอม 1 / เทอม 2) |
| **โหมด Card/Table** | สลับการแสดงผล |
| **ดาวน์โหลด PDF** | ส่งออกมุมมองนี้เป็น PDF |
| **แชร์ลิงก์** | ได้ URL ที่สามารถส่งให้ผู้อื่น (ต้องอยู่ในโรงเรียนเดียวกันจึงเปิดได้) |
| **พิมพ์** | ส่งไปหน้าพิมพ์โดยตรง — ดูที่ [พิมพ์](/timetable/printing) |

## กรอง/ค้นหา

ช่องค้นหาด้านบน — พิมพ์เพื่อกรอง (ครู/ห้อง/วิชา) แบบ real-time

## ข้อจำกัด

- **ดูอย่างเดียว** — ไม่สามารถลาก/แก้ไขคาบในโหมดนี้ ต้องไปที่ [Editor](/timetable/editing)
- **อิงตามแฟ้มที่เลือก** — ถ้ามีหลายภาคเรียน ต้องเลือกแฟ้มให้ถูก

## Public Link (แชร์กับนักเรียน)

เจ้าของสามารถเปิด **link แบบ public** ให้นักเรียนเปิดดูตารางเรียนของห้องตัวเองได้ทันที โดยไม่ต้องสมัครบัญชี Tarangson — link จะมี token ปกป้องข้อมูลบุคคลอื่น

**วิธีเปิด:**
1. ใน Editor → เมนูส่วน **"แชร์"** → เลือก **"เปิด public link"**
2. Copy URL แล้วส่งให้นักเรียนผ่าน LINE / Facebook
3. ปิดได้ทุกเมื่อจากเมนูเดิม
