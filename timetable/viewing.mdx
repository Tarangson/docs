## ภาพรวม

หน้าดูตารางสอนเป็นหน้าสำหรับแสดงตารางสอนแบบอ่านอย่างเดียว (Read-Only) คุณสามารถเลือกดูตารางจากมุมมองต่าง ๆ ได้โดยไม่สามารถแก้ไขข้อมูลตาราง เหมาะสำหรับการตรวจสอบตาราง แชร์ให้ครูผู้สอน หรือพิมพ์ออกมา

## มุมมองที่มีให้เลือก

<Tabs>
  <Tab title="มุมมองผู้สอน">
    **ตารางสอนผู้สอน** (`/timetable/view/teacher`)

    แสดงตารางสอนของผู้สอนแต่ละคน โดยแสดงข้อมูลวิชา ผู้เรียน และห้องเรียนในแต่ละคาบ

    เลือกผู้สอนที่ต้องการดูจากรายการด้านซ้ายมือ
  </Tab>

  <Tab title="มุมมองผู้เรียน">
    **ตารางเรียนผู้เรียน** (`/timetable/view/student`)

    แสดงตารางเรียนของผู้เรียนแต่ละกลุ่ม โดยแสดงข้อมูลผู้สอน วิชา และห้องเรียนในแต่ละคาบ

    เลือกผู้เรียน (ห้อง/กลุ่ม) ที่ต้องการดูจากรายการด้านซ้ายมือ
  </Tab>

  <Tab title="มุมมองห้องเรียน">
    **ตารางห้องเรียน** (`/timetable/view/room`)

    แสดงตารางการใช้งานของห้องเรียนแต่ละห้อง โดยแสดงข้อมูลผู้สอน วิชา และผู้เรียนในแต่ละคาบ

    เลือกห้องเรียนที่ต้องการดูจากรายการด้านซ้ายมือ
  </Tab>
</Tabs>

## การสลับมุมมอง

คุณสามารถสลับระหว่างมุมมองผู้สอน ผู้เรียน และห้องเรียนได้จาก dropdown ที่ส่วนหัวของหน้า:

1. คลิกที่ dropdown **เลือกมุมมอง** (แสดงชื่อมุมมองปัจจุบัน เช่น "ตารางสอนผู้สอน")
2. เลือกมุมมองที่ต้องการ
3. ระบบจะเปลี่ยนหน้าไปยังมุมมองที่เลือกโดยยังใช้แฟ้มงานเดิม

## มุมมองการ์ด (Card Mode) กับมุมมองตาราง

<Cards>
  <Card title="มุมมองตาราง (ปกติ)">
    แสดงข้อมูลในแต่ละช่องเป็นข้อความธรรมดา เหมาะสำหรับดูข้อมูลภาพรวม
  </Card>
  <Card title="มุมมองการ์ด">
    แสดงข้อมูลในแต่ละช่องเป็นการ์ดที่มีกรอบสีแบ่งแยกชัดเจน เหมาะสำหรับการพิมพ์
  </Card>
</Cards>

สลับโหมดได้โดยคลิกไอคอน **ตาราง** (LayoutGrid) ที่แถบเครื่องมือด้านขวา:
- เมื่อเปิดมุมมองการ์ด ไอคอนจะเปลี่ยนเป็นสีเน้น
- เมื่อปิดมุมมองการ์ด ไอคอนจะเป็นสีเทา

## เครื่องมือที่มีให้ใช้

แถบเครื่องมือด้านขวามือมีฟังก์ชันดังนี้:

| เครื่องมือ | ไอคอน | คำอธิบาย |
|---|---|---|
| **โหลดข้อมูลใหม่** | RefreshCw | โหลดข้อมูลตารางสอนใหม่จากเซิร์ฟเวอร์ |
| **มุมมองการ์ด** | LayoutGrid | สลับระหว่างมุมมองการ์ดและมุมมองตาราง |
| **สลับแกน** | ArrowLeftRight | สลับระหว่าง "วันเป็นแถว / คาบเป็นคอลัมน์" กับ "คาบเป็นแถว / วันเป็นคอลัมน์" |
| **ตั้งค่าการแสดงผล** | SlidersHorizontal | เลือกฟิลด์ที่จะแสดงในการ์ด (สูงสุด 2 ฟิลด์ต่อประเภท) |
| **ขยาย / ย่อ** | ZoomIn / ZoomOut | ปรับขนาดตาราง (3 ระดับ) |
| **ขนาดพอดี** | Maximize2 | รีเซ็ตขนาดกลับเป็นค่ากลาง |

## การตั้งค่าการแสดงผลในการ์ด

คุณสามารถเลือกฟิลด์ที่จะแสดงในแต่ละแถวของการ์ดได้ โดยคลิกไอคอน **ตั้งค่าการแสดงผล** แล้วเลือกฟิลด์ที่ต้องการ:

**ผู้สอน:** รหัส, คำนำหน้า, ชื่อ, นามสกุล, หมวด/ฝ่าย (รวมถึง custom field)

**วิชาเรียน:** รหัสวิชา, ชื่อวิชา

**ผู้เรียน:** รหัส, ชั้นเรียน, ระดับชั้น (รวมถึง custom field)

**ห้องเรียน:** รหัสห้อง, ชื่อห้อง, รายละเอียด

<Callout type="info">
  คุณสามารถเลือกได้สูงสุด 2 ฟิลด์ต่อประเภท นอกจากนี้ยังสามารถเลือก **ซ่อนเมื่ออยู่ในมุมมองของตัวเอง** ได้ เช่น ซ่อนแถวผู้สอนเมื่ออยู่ในมุมมองผู้สอน (เพราะรู้อยู่แล้วว่าเป็นผู้สอนคนไหน)
</Callout>

## การเลือกแฟ้มงาน

เมื่อเข้าหน้าดูตารางสอน ระบบจะแสดง dialog ให้คุณเลือกแฟ้มงานที่ต้องการดู โดยแสดงข้อมูล:

- ชื่อแฟ้มงาน
- วันที่สร้าง
- รายละเอียด (ถ้ามี)
- วันเริ่มต้นและสิ้นสุด (ถ้ามี)

## การค้นหาและกรอง

คุณสามารถค้นหาและกรองรายชื่อหลัก (ผู้สอน ผู้เรียน หรือห้องเรียน) ได้จากแถบด้านซ้าย:

- **ค้นหา** — พิมพ์ชื่อ รหัส หรือข้อมูลอื่น ๆ
- **กรอง** — กรองตาม custom field ที่เป็นประเภท select
- **เรียงลำดับ** — เรียงจาก ก-ฮ หรือ ฮ-ก

## คาบพิเศษ

คาบที่สร้างจาก Wizard Template (คาบพิเศษ) จะแสดงด้วยสีฟ้าอ่อนเพื่อให้แยกแยะจากคาบปกติได้ง่าย เมื่อคาบมีผู้สอน ผู้เรียน หรือห้องเรียนหลายรายการ ระบบจะแสดงคำว่า "หลาย" แทนชื่อ
