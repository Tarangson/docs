การสร้างแฟ้มตารางสอนใน ตารางสอน มี 3 ขั้นตอนหลัก — **เช็คลิสต์ → ดำเนินการ → เข้าสู่ Editor**

## ขั้นตอนที่ 1 — กดปุ่ม "สร้างแฟ้มใหม่"

จาก [หน้าแฟ้มจัดตารางสอน](/timetable/files) กดปุ่ม **"+ สร้างแฟ้มใหม่"** สีเขียวมุมขวาบน

## ขั้นตอนที่ 2 — ผ่านหน้าเช็คลิสต์

<img src="/images/screens/timetable-new.png" alt="เช็คลิสต์ก่อนสร้างแฟ้ม" />

ระบบจะพาไปที่ `/timetable/new` ซึ่งเป็น**หน้าเช็คลิสต์บังคับ** — ดูรายละเอียดของ 5 กลุ่มข้อมูลได้ที่ [เช็คลิสต์ก่อนสร้างตารางสอน](/getting-started/setup-wizard)

ต้องมีข้อมูลพร้อมอย่างน้อย **1 รายการ** ในแต่ละกลุ่ม:

| กลุ่ม | ขั้นต่ำ |
| --- | --- |
| ตารางเรียนพื้นฐาน | 1 ชุด |
| ผู้สอน | ≥ 1 คน |
| ผู้เรียน (ห้องเรียน) | ≥ 1 ห้อง |
| ห้องเรียน (กายภาพ) | ≥ 1 ห้อง |
| วิชาเรียน | ≥ 1 วิชา |

<Warning>
  โดยปกติโรงเรียนจริงจะมีข้อมูลหลายสิบถึงหลายร้อยในแต่ละกลุ่ม — ควรเพิ่มให้ครบก่อนสร้างแฟ้มเพราะ**เพิ่มฟิลด์ข้อมูลหลังสร้างไม่ได้**
</Warning>

## ขั้นตอนที่ 3 — ยืนยันและกดดำเนินการ

- ติ๊กช่อง **"ข้าพเจ้าได้ตรวจสอบและเพิ่มข้อมูลข้างต้นเรียบร้อยแล้ว"**
- กดปุ่ม **"ดำเนินการต่อ"** (สีเขียว)

## ขั้นตอนที่ 4 — ตั้งชื่อแฟ้ม

Dialog จะขึ้นให้ตั้งชื่อแฟ้ม:

| ช่อง | ตัวอย่าง |
| --- | --- |
| **ชื่อแฟ้ม \*** | เทอม 1 / 2569 |
| **ภาคเรียน** (dropdown) | เทอม 1 / เทอม 2 / ภาคฤดูร้อน |
| **ปีการศึกษา** (input) | 2569 |
| **หมายเหตุ** (optional) | |

กด **สร้าง** — ระบบจะสร้างแฟ้มใหม่และเปิด Editor ทันที

## ขั้นตอนที่ 5 — อยู่ใน Editor แล้ว

หน้าต่อไปจะเป็น**หน้า Editor ตารางสอน** (`/timetable?fileId=xxx`) ซึ่งเป็นพื้นที่ทำงานหลัก — ดูต่อที่ [แก้ไขตารางสอน](/timetable/editing)

## การสร้างแฟ้มจาก Clone

อีกวิธีหนึ่งคือ **ทำสำเนา** จากแฟ้มเดิม — เหมาะสำหรับการสร้าง "เทอม 2" ต่อจาก "เทอม 1"

<Steps>
  <Step title="ที่หน้าแฟ้มจัดตารางสอน">
    กด ⋮ บนแฟ้มต้นแบบ → **"ทำสำเนา"**
  </Step>
  <Step title="ตั้งชื่อใหม่">
    ระบบจะเติมชื่อ `ชื่อเดิม (สำเนา)` ให้ — เปลี่ยนเป็น "เทอม 2 / 2569"
  </Step>
  <Step title="เปิด Editor">
    แฟ้มใหม่จะมี **โครงตารางทั้งหมดจากแฟ้มเดิม** รวมคาบที่จัดไว้แล้ว — แก้ไขและลบเฉพาะส่วนที่ต้องการ
  </Step>
</Steps>

## เคล็ดลับตั้งชื่อแฟ้ม

ชื่อที่แนะนำ:
- `เทอม 1 / 2569`
- `เทอม 2 / 2569`
- `ภาคฤดูร้อน 2568`
- `แผนสำรอง — เทอม 1 / 2569`

ไม่แนะนำ:
- `ตาราง` (สั้นเกินไป)
- `Term1_2024_v3_final_final_real` (ยาว สับสน)
