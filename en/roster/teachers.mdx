The teacher management page lets you maintain records for all teachers in your school. It supports searching, sorting, importing from Excel, and adding custom fields as needed.

<Frame>
  <img src="/images/teachers.png" alt="Teacher Management Page" />
</Frame>

## Default Teacher Fields

Each teacher record includes the following default fields:

| Field | Description | Required |
|-------|------------|----------|
| Teacher ID (รหัสผู้สอน) | A unique identifier for the teacher, e.g. `T001` | No |
| Title/Prefix (คำนำหน้า) | Name prefix, e.g. Mr. (นาย), Mrs. (นาง), Ms. (นางสาว) | No |
| First Name (ชื่อ) | The teacher's first name | Yes |
| Last Name (นามสกุล) | The teacher's last name | Yes |
| Department (หมวด/ฝ่าย) | Subject group or department, e.g. Science, Mathematics | Yes |

<Callout type="info">
  These 5 default fields cannot be deleted, but you can add custom fields as needed.
</Callout>

## Add a New Teacher

<Steps>
  <Step title="Open the add form">
    Click the **+ Add** button at the top of the table. A form dialog will appear.
  </Step>
  <Step title="Fill in the details">
    Complete the teacher form. At minimum, you must provide **First Name**, **Last Name**, and **Department**.

    - **Title/Prefix** -- select from a dropdown, e.g. Mr. (นาย), Mrs. (นาง), Ms. (นางสาว)
    - **Department** -- select from a preconfigured dropdown list
    - If you have custom fields, additional input fields will appear in the form as well
  </Step>
  <Step title="Save">
    Click **Save** to add the teacher to the table.
  </Step>
</Steps>

## Edit Teacher Data

Click the pencil (edit) icon in the rightmost column of the row you want to edit. The same form used for adding data will open, pre-filled with the existing information for you to modify.

## Delete Teachers

<Steps>
  <Step title="Select entries">
    Check the checkbox on the left side of each row you want to delete. You can select individual entries or check the table header checkbox to select all entries on the current page.
  </Step>
  <Step title="Confirm deletion">
    Click the **Delete** button in the toolbar at the top. The system will ask for confirmation before deleting.
  </Step>
</Steps>

<Callout type="warning">
  When you select all entries on the current page, the system will also offer an option to **select all entries across all pages**. Please double-check before deleting, as deletions cannot be undone.
</Callout>

## Search and Filter

Type your query in the **Search** box above the table. The system filters results in real-time across the following fields:

- Teacher ID (รหัสผู้สอน)
- First Name (ชื่อ)
- Last Name (นามสกุล)
- Department (หมวด/ฝ่าย)

## Sorting

You can sort data in 3 ways by clicking on a column header:

| Sort Mode | Description |
|-----------|------------|
| Order (default) | Custom ordering that supports drag-and-drop |
| ID | Sort by Teacher ID, ascending or descending |
| Department | Sort by department name |

Click the same column header again to toggle between ascending (asc) and descending (desc) order.

## Drag-and-Drop Reordering

When sorting by **Order** (the default), you will see a six-dot grip icon in the order column.

<Steps>
  <Step title="Grab the drag handle">
    Click and hold the six-dot grip icon on the left side of a row.
  </Step>
  <Step title="Drag to the new position">
    Drag the row up or down to the desired position.
  </Step>
  <Step title="Drop">
    Release the mouse button. The system will save the new order automatically.
  </Step>
</Steps>

<Callout type="info">
  The drag handle only appears when sorting by "Order." If you sort by ID or Department, drag-and-drop reordering is not available.
</Callout>

## Configure Title/Prefix and Department Options

Title/Prefix and Department are dropdown fields whose options you can customize.

### Edit Title/Prefix Options

The defaults are: Mr. (`นาย`), Mrs. (`นาง`), Ms. (`นางสาว`)

You can add other options such as `ครู` (Teacher), `อาจารย์` (Instructor), `ดร.` (Dr.) by opening the title/prefix options manager.

### Edit Department Options

The defaults are: `วิทยาศาสตร์` (Science), `คณิตศาสตร์` (Mathematics)

You can add other departments such as `ภาษาไทย` (Thai Language), `ภาษาอังกฤษ` (English), `สังคมศึกษา` (Social Studies) to match your school's structure.

## Custom Fields

In addition to the default fields, you can create custom fields to store any additional information you need.

<Steps>
  <Step title="Open the field manager">
    Click the **Manage Fields** button in the toolbar at the top.
  </Step>
  <Step title="Add a new field">
    Choose the field type you need:

    - **Text** (`text`) -- a free-text input
    - **Number** (`number`) -- a numeric input
    - **Select** (`select`) -- a dropdown with predefined options
  </Step>
  <Step title="Name and save">
    Enter a name for the field. If the type is **Select**, define at least 1 option. Then click **Save**.
  </Step>
</Steps>

<Callout type="warning">
  Deleting a custom field will also remove its data from all teacher records. The system will ask for confirmation before deleting.
</Callout>

## Import and Export Excel

You can import teacher data from Excel or export all data to an Excel file. For more details, see the [Import and Export Excel](/roster/excel) page.

<Tabs>
  <Tab title="Export Excel">
    Click the **Export Excel** button. The system will download a file named `ผู้สอน.xlsx` (Teachers) containing all teacher data, including custom fields.
  </Tab>
  <Tab title="Import Excel">
    1. Click the **Import Excel** button and select an `.xlsx`, `.xls`, or `.csv` file
    2. The system will show a preview of the data for you to review
    3. Choose an import mode: **Append** or **Replace All**
    4. Click **Confirm** to import
  </Tab>
  <Tab title="Download Template">
    Click the **Download Template** button to get an empty Excel file with the correct column headers, including any custom fields you have configured.
  </Tab>
</Tabs>

### Required Excel Columns

| Column | Required |
|--------|----------|
| `รหัสครู` (Teacher ID) | Yes |
| `คำนำหน้า` (Title/Prefix) | Yes |
| `ชื่อ` (First Name) | Yes |
| `นามสกุล` (Last Name) | Yes |
| `หมวด/ฝ่าย` (Department) | Yes |

Custom field columns will use the names you assigned when creating them.

## Pagination

The table displays data in pages. By default, 25 entries are shown per page. You can change the number of entries per page and navigate between pages using the controls at the bottom of the table.
