The subject management page lets you maintain records of all subjects offered by your school, such as Basic Mathematics, Science, English, and more. Subject data is used when building your timetable.

<Frame>
  <img src="/images/subjects.png" alt="Subject Management Page" />
</Frame>

## Default Subject Fields

Each subject entry includes the following default fields:

| Field | Description | Example |
|-------|------------|---------|
| Subject Code (รหัสวิชา) | A unique identifier for the subject | `MAT101` |
| Subject Name (ชื่อรายวิชา) | The full name of the subject | `Basic Mathematics` (คณิตศาสตร์พื้นฐาน) |

<Callout type="info">
  These 2 default fields cannot be deleted, but you can add custom fields as needed.
</Callout>

## Add a New Subject

<Steps>
  <Step title="Open the add form">
    Click the **+ Add** button at the top of the table.
  </Step>
  <Step title="Fill in the details">
    Complete the form:

    - **Subject Code** -- a unique identifier, e.g. `SCI201`
    - **Subject Name** -- the full name, e.g. `Additional Science` (วิทยาศาสตร์เพิ่มเติม)
    - If you have custom fields, additional input fields will appear in the form as well
  </Step>
  <Step title="Save">
    Click **Save** to add the subject to the table.
  </Step>
</Steps>

## Edit Subject Data

Click the pencil (edit) icon in the rightmost column of the row you want to edit. The same form used for adding data will open, pre-filled with the existing information for you to modify.

## Delete Subjects

<Steps>
  <Step title="Select entries">
    Check the checkbox on the left side of each row you want to delete. You can select individual entries or check the table header checkbox to select all entries on the current page.
  </Step>
  <Step title="Confirm deletion">
    Click the **Delete** button in the toolbar at the top. The system will ask for confirmation before deleting.
  </Step>
</Steps>

<Callout type="warning">
  When you select all entries on the current page, the system will also offer an option to **select all entries across all pages**. Deletions cannot be undone.
</Callout>

## Search and Filter

Type your query in the **Search** box above the table. The system filters results in real-time across the following fields:

- Subject Code (รหัสวิชา)
- Subject Name (ชื่อรายวิชา)

## Sorting

You can sort data in 3 ways by clicking on a column header:

| Sort Mode | Description |
|-----------|------------|
| Order (default) | Custom ordering that supports drag-and-drop |
| Code | Sort by Subject Code |
| Name | Sort by Subject Name |

Click the same column header again to toggle between ascending (asc) and descending (desc) order.

## Drag-and-Drop Reordering

When sorting by **Order** (the default), you will see a six-dot grip icon in the order column.

<Steps>
  <Step title="Grab the drag handle">
    Click and hold the six-dot grip icon on the left side of a row.
  </Step>
  <Step title="Drag to the new position">
    Drag the row up or down to the desired position.
  </Step>
  <Step title="Drop">
    Release the mouse button. The system will save the new order automatically.
  </Step>
</Steps>

<Callout type="info">
  The drag handle only appears when sorting by "Order." If you sort by Code or Name, drag-and-drop reordering is not available.
</Callout>

## Custom Fields

In addition to the default fields, you can create custom fields to store any additional information you need, such as credit hours or subject type.

<Steps>
  <Step title="Open the field manager">
    Click the **Manage Fields** button in the toolbar at the top.
  </Step>
  <Step title="Add a new field">
    Choose the field type you need:

    - **Text** (`text`) -- a free-text input
    - **Number** (`number`) -- a numeric input, e.g. credit hours
    - **Select** (`select`) -- a dropdown with predefined options, e.g. subject type (Core / Elective)
  </Step>
  <Step title="Name and save">
    Enter a name for the field. If the type is **Select**, define at least 1 option. Then click **Save**.
  </Step>
</Steps>

<Callout type="warning">
  Deleting a custom field will also remove its data from all subject entries. The system will ask for confirmation before deleting.
</Callout>

## Import and Export Excel

You can import data from Excel or export all data to an Excel file. For more details, see the [Import and Export Excel](/roster/excel) page.

<Tabs>
  <Tab title="Export Excel">
    Click the **Export Excel** button. The system will download a file named `วิชาเรียน.xlsx` (Subjects) containing all subject data, including custom fields.
  </Tab>
  <Tab title="Import Excel">
    1. Click the **Import Excel** button and select an `.xlsx`, `.xls`, or `.csv` file
    2. The system will show a preview of the data for you to review
    3. Choose an import mode: **Append** or **Replace All**
    4. Click **Confirm** to import
  </Tab>
  <Tab title="Download Template">
    Click the **Download Template** button to get an empty Excel file with the correct column headers, including any custom fields you have configured.
  </Tab>
</Tabs>

### Required Excel Columns

| Column | Required |
|--------|----------|
| `รหัสวิชา` (Subject Code) | Yes |
| `ชื่อรายวิชา` (Subject Name) | Yes |

<Callout type="info">
  The system requires both **รหัสวิชา** (Subject Code) and **ชื่อรายวิชา** (Subject Name) columns. Rows missing both code and name will be skipped automatically.
</Callout>

Custom field columns will use the names you assigned when creating them.

## Pagination

The table displays data in pages. By default, 25 entries are shown per page. You can change the number of entries per page and navigate between pages using the controls at the bottom of the table.
