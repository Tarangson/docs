The file `app/lib/types.ts` contains all shared type definitions used throughout the app. They are organized into 3 categories:

1. **Academic Defaults** -- base academic data types
2. **Timetable File** -- timetable file data types
3. **Wizard Templates** -- wizard system template types

---

## Academic Defaults Types

### `DayOfWeek`

```typescript
type DayOfWeek = "MON" | "TUE" | "WED" | "THU" | "FRI" | "SAT" | "SUN";
```

Union type for days of the week. Used as keys in schedules (e.g., `"MON_1"`, `"TUE_3"`).

### `PeriodTime`

```typescript
interface PeriodTime {
  start: string; // "HH:mm" e.g., "08:30"
  end: string;   // "HH:mm" e.g., "09:20"
}
```

### `PeriodGenSettings`

```typescript
interface PeriodGenSettings {
  periodDuration: number; // Minutes per period (e.g., 50)
  breakDuration: number;  // Minutes between periods (e.g., 10)
}
```

Helper for auto-generating period times.

### `CustomFieldDef`

```typescript
interface CustomFieldDef {
  id: string;
  label: string;
  type: "text" | "number" | "select";
  options?: string[]; // For type "select"
}
```

Definition of a custom field that schools can create on their own. Stored in the `_settings` document of each entity collection.

### `SpecialPeriodsInfo`

```typescript
interface SpecialPeriodsInfo {
  id: string;    // Group ID, e.g., "sp_l3x2k4_abc123"
  type: string;  // "wizard" | "multiTeacher" | "multiStudent" | "multiRoom" | ...
}
```

Used to mark a timeslot as a special period (wizard mode). Supports backward compatibility with the legacy string format.

## Wizard Template Types

### `WizardConfigMode`

```typescript
type WizardConfigMode = "none" | "single" | "multi";
```

Determines how many entities of a given type can be selected:
- `"none"` -- not used
- `"single"` -- select 1
- `"multi"` -- select multiple

### `WizardConfig`

```typescript
type WizardConfig = {

```

```typescript
interface WizardTemplate {
```

## Helper Functions

### `generateId(prefix)`

```typescript
function generateId(prefix: string): string {
  return `${prefix}_${Date.now().toString(36)}_${Math.random().toString(36).slice(2, 8)}`;
}
```

Generates a unique ID from a timestamp + random string. Uses different prefixes per entity type:
- `"t"` -- teacher
- `"st"` -- student
- `"r"` -- room
- `"sub"` -- subject
- `"sp"` -- special periods

### `getSpecialPeriodsType(sp)`

```typescript
function getSpecialPeriodsType(
  sp: SpecialPeriodsInfo | string | undefined
): string | undefined
```

Extracts the `type` from the `specialPeriods` field. Supports both the legacy format (string) and the new format (object).

### `isWizardType(sp)`

```typescript
function isWizardType(
  sp: SpecialPeriodsInfo | string | undefined
): boolean
```

Checks whether `specialPeriods` is of wizard type (backward-compatible).

### `isSpecialType(sp)`

```typescript
function isSpecialType(
  sp: SpecialPeriodsInfo | string | undefined
): boolean
```

Checks whether `specialPeriods` exists (backward-compatible truthy check).

## Constants

```typescript
const DEFAULT_ACADEMIC: AcademicDefaults = {
  timezone: "Asia/Bangkok",
  days: ["MON", "TUE", "WED", "THU", "FRI"],
  periodCount: 8,
  periods: {
    "1": { start: "08:30", end: "09:20" },
    "2": { start: "09:30", end: "10:20" },
    "3": { start: "10:30", end: "11:20" },
    "4": { start: "11:30", end: "12:20" },
    "5": { start: "13:10", end: "14:00" },
    "6": { start: "14:10", end: "15:00" },

  },
```

### `DAY_LABELS`

```typescript
const DAY_LABELS: Record<DayOfWeek, string> = {
  MON: "จันทร์",
  TUE: "อังคาร",
  WED: "พุธ",
  THU: "พฤหัสบดี",
  FRI: "ศุกร์",
  SAT: "เสาร์",
  SUN: "อาทิตย์",
};
```

Maps `DayOfWeek` codes to Thai day names (จันทร์ = Monday, อังคาร = Tuesday, พุธ = Wednesday, พฤหัสบดี = Thursday, ศุกร์ = Friday, เสาร์ = Saturday, อาทิตย์ = Sunday).

### `ALL_DAYS`

```typescript
const ALL_DAYS: DayOfWeek[] = [
  "MON", "TUE", "WED", "THU", "FRI", "SAT", "SUN"
];
```

All days in order (including Saturday and Sunday).
