## Tech Stack

Tarangson webapp is built with the following modern stack:

| Technology | Version | Purpose |
|---|---|---|
| **Next.js** | 16.1.6 | App Router framework |
| **React** | 19.2.3 | UI library |
| **TypeScript** | ^5 | Type-safe JavaScript |
| **Tailwind CSS** | ^4 | Utility-first CSS framework |
| **shadcn/ui** | ^3.8.4 (CLI) | Component library built on Radix UI |
| **Radix UI** | ^1.4.3 | Accessible UI primitives |
| **Firebase** | ^12.9.0 | Auth, Firestore, Storage |
| **dnd-kit** | ^6.3.1 (core) | Drag-and-drop for timetable scheduling |
| **XLSX (SheetJS)** | ^0.18.5 | Import/Export Excel |
| **Sonner** | ^2.0.7 | Toast notifications |
| **Lucide React** | ^0.564.0 | Icon library |

### Additional Libraries

- **class-variance-authority** -- manages component style variants
- **clsx** + **tailwind-merge** -- manages conditional class names
- **next-themes** -- Dark/Light mode
- **thai-address-autocomplete-react** -- Thai address autocomplete

## Key Architectural Principles

### App Router (Next.js 16)

The entire application uses the Next.js App Router -- every page lives under the `app/` directory and uses the `"use client"` directive, since this is a client-side application that depends on Firebase Auth state.

### Authentication Flow

```
layout.tsx (AuthProvider)
  └── ProtectedRoute
       ├── Not logged in → redirect /login
       ├── Setup incomplete → redirect /setup
       └── Ready → render children
```

### Data Architecture

All data is stored in **Firestore** using a document-based schema:

- **School-scoped data** -- uses `{schoolId}` as the root document
- **Roster data** -- stored as sub-collections under `academicDefaults`
- **Timetable data** -- denormalized into 3 collections (teachers/students/rooms) for fast queries

### Denormalized Schedule Storage

<Callout type="info">
  Timetable data is stored in a **denormalized** fashion -- written redundantly across 3 collections (teacher, student, room) so that loading each view is fast without cross-collection queries. Every write uses `runTransaction` to prevent conflicts.
</Callout>

### Font & Localization

- Uses the **Kanit** font for Thai text (Google Fonts)
- Primary language is Thai (`lang="th"`)
- Default timezone: `Asia/Bangkok`
