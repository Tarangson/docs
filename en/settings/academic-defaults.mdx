## Overview

The Academic Defaults page is where you configure the default timetable settings for your entire school, including school days, number of periods, period times, and timezone. These settings serve as the base template when you create a new timetable file. You can adjust them again when you start scheduling.

You can access this page from the Dashboard by clicking the **Timetable Defaults** (ตารางเรียนพื้นฐาน) card, or by navigating to `/academic`.

## System Defaults

| Setting | Default Value |
|---|---|
| Timezone | `Asia/Bangkok` (UTC+7) |
| School Days | Monday -- Friday |
| Number of Periods | 8 |
| First Period Start Time | 08:30 |
| Period Duration | 50 minutes |
| Break Between Periods | 10 minutes |

## School Days

Click a day button to toggle it on or off. Selected days are highlighted in green with a checkmark.

Available days:

| Code | Day |
|---|---|
| `MON` | Monday |
| `TUE` | Tuesday |
| `WED` | Wednesday |
| `THU` | Thursday |
| `FRI` | Friday |
| `SAT` | Saturday |
| `SUN` | Sunday |

<Callout type="info" title="Adding Saturday and Sunday">
  If your school holds classes on Saturday or Sunday, you can add them by clicking the **Saturday** (เสาร์) or **Sunday** (อาทิตย์) button.
</Callout>

## Class Periods

### Period Label

You can choose a period label from the preset list or define your own:

| Option | Display Example |
|---|---|
| Period (คาบ) (default) | Period 1, Period 2, ... |
| Hour (ชั่วโมง) | Hour 1, Hour 2, ... |
| Class Hour (ชั่วโมงเรียน) | Class Hour 1, Class Hour 2, ... |
| Custom (อื่นๆ) | Define your own label |

### Number of Periods and Times

<Steps>
  <Step title="Set the number of periods">
    Adjust the number of periods by typing a number in the **Number of Periods** (จำนวนคาบ) field or clicking the **+** / **-** buttons to increase or decrease it. The system supports 1 to 20 periods.
  </Step>
  <Step title="Set the period duration">
    Enter the number of minutes per period in the **Minutes per Period** (นาที/คาบ) field. The default is 50 minutes.
  </Step>
  <Step title="Set the break duration">
    Enter the number of minutes in the **Break Between Periods** (พักระหว่างคาบ) field. The default is 10 minutes.
  </Step>
  <Step title="Enter the first period start time">
    Enter the start time for Period 1 in the time field below, for example `08:30`.
  </Step>
  <Step title="Click Calculate Times">
    Click the **Calculate Times** (คำนวณเวลา) button. The system will automatically calculate the start and end times for every period based on the first period start time, period duration, and break time.
  </Step>
</Steps>

<Callout type="tip" title="Lunch break included">
  The system calculates all period times continuously, including the lunch break. If you want to insert a lunch gap, you can manually edit individual period times after the automatic calculation.
</Callout>

### Edit Times Manually

You can edit the start and end times for any individual period by clicking the time field for the period you want to change and selecting a new time.

## Timezone

The timezone setting is located at the bottom of the page. The default is **Thailand / Bangkok (UTC+7)**.

<Callout type="info" title="When should you change the timezone?">
  Change the timezone if your school or branch is located outside Thailand, or if you run an online homeschool program with students in different time zones.
</Callout>

The system supports timezones worldwide, covering the following regions:

- Southeast Asia
- East Asia
- South Asia
- Central Asia
- Middle East
- Europe
- Africa
- North America
- South America
- Oceania

---

## Save Settings

Once you have finished adjusting all settings, click the **Save** (บันทึก) button in the bottom-right corner. The system will display a "Saved!" (บันทึกแล้ว!) message when the save is successful.

<Callout type="warning" title="Don't forget to save">
  All changes only take effect when you click the **Save** (บันทึก) button. If you leave this page without saving, your changes will be lost.
</Callout>
