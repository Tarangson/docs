## Overview

The timetable viewing page displays the timetable in read-only mode. You can view the timetable from different perspectives without being able to edit the data. This is ideal for reviewing the schedule, sharing it with teachers, or printing it out.

## Available Views

<Tabs>
  <Tab title="Teacher View">
    **Teacher Timetable** (`/timetable/view/teacher`)

    Displays each teacher's timetable, showing the subject, student group, and room for each period.

    Select the teacher you want to view from the list on the left side.
  </Tab>

  <Tab title="Student View">
    **Student Timetable** (`/timetable/view/student`)

    Displays each student group's timetable, showing the teacher, subject, and room for each period.

    Select the student group (class/section) you want to view from the list on the left side.
  </Tab>

  <Tab title="Room View">
    **Room Timetable** (`/timetable/view/room`)

    Displays the usage schedule for each room, showing the teacher, subject, and student group for each period.

    Select the room you want to view from the list on the left side.
  </Tab>
</Tabs>

## Switching Views

You can switch between the Teacher, Student, and Room views from the dropdown in the page header:

1. Click the **Select View** dropdown (which displays the current view name, e.g., "Teacher Timetable").
2. Select the desired view.
3. The system will navigate to the selected view while keeping the same timetable file.

## Card Mode vs. Table Mode

<Cards>
  <Card title="Table Mode (Default)">
    Displays data in each cell as plain text. Suitable for viewing the overall schedule at a glance.
  </Card>
  <Card title="Card Mode">
    Displays data in each cell as a card with colored borders for clear visual separation. Suitable for printing.
  </Card>
</Cards>

You can toggle the mode by clicking the **Table** icon (LayoutGrid) in the toolbar on the right:
- When card mode is active, the icon appears in the accent color.
- When card mode is off, the icon appears in gray.

## Available Tools

The toolbar on the right side provides the following functions:

| Tool | Icon | Description |
|---|---|---|
| **Reload Data** | RefreshCw | Reload the timetable data from the server. |
| **Card Mode** | LayoutGrid | Toggle between card mode and table mode. |
| **Toggle Axis** | ArrowLeftRight | Switch between "days as rows / periods as columns" and "periods as rows / days as columns." |
| **Display Settings** | SlidersHorizontal | Choose which fields to show in the card (up to 2 fields per category). |
| **Zoom In / Zoom Out** | ZoomIn / ZoomOut | Adjust the table size (3 levels). |
| **Fit to Size** | Maximize2 | Reset the size to the default level. |

## Configuring Card Display Fields

You can choose which fields to display in each row of the card by clicking the **Display Settings** icon and selecting the fields you want:

**Teacher:** Code, Prefix, First Name, Last Name, Department (including custom fields)

**Subject:** Subject Code, Subject Name

**Student:** Code, Class, Grade Level (including custom fields)

**Room:** Room Code, Room Name, Description

<Callout type="info">
  You can select up to 2 fields per category. You can also choose **Hide when viewing own category** — for example, hide the teacher row when you are in the Teacher View (since you already know which teacher it is).
</Callout>

## Selecting a File

When you open the timetable viewing page, the system displays a dialog for you to select the file you want to view, showing:

- File name
- Creation date
- Description (if available)
- Start and end dates (if available)

## Search and Filter

You can search and filter the primary list (teachers, students, or rooms) from the left panel:

- **Search** — Type a name, code, or other information.
- **Filter** — Filter by custom fields of the select type.
- **Sort** — Sort from A–Z or Z–A.

## Special Periods

Periods created by the Wizard Template (special periods) are displayed with a light blue background to easily distinguish them from regular periods. When a period has multiple teachers, students, or rooms, the system displays "Multiple" instead of the individual names.
