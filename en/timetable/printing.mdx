## Overview

You can print the timetable from the timetable viewing page by enabling Card Mode to make the layout print-friendly, then using the browser's Print function.

## How to Print the Timetable

<Steps>
  <Step title="Open the timetable viewing page">
    Go to the **View Timetable** page and select the view you want (Teacher, Student, or Room).
  </Step>

  <Step title="Select a file">
    Choose the file you want to print from the file selection dialog.
  </Step>

  <Step title="Select the item to print">
    Select the teacher, student group, or room whose timetable you want to print from the list on the left side.
  </Step>

  <Step title="Enable card mode">
    Click the **LayoutGrid** icon in the toolbar on the right to enable card mode. The data in the table will be displayed as cards with borders and background colors for clear visual separation, making it suitable for printing.

    <Callout type="tip">
      In card mode, all text is displayed in black for better readability when printed.
    </Callout>
  </Step>

  <Step title="Adjust display settings (optional)">
    Click the **Display Settings** icon (SlidersHorizontal) to choose which fields to show in the cards — for example, showing the subject code instead of the subject name, or showing the teacher's first and last name.
  </Step>

  <Step title="Adjust the size (optional)">
    Use the **Zoom In** (ZoomIn) or **Zoom Out** (ZoomOut) buttons to resize the table to fit the paper.
  </Step>

  <Step title="Print">
    Press `Ctrl+P` (Windows) or `Cmd+P` (Mac) to open the browser's Print dialog, then configure your print settings as needed.
  </Step>
</Steps>

## Printing Tips

<Cards>
  <Card title="Use landscape orientation">
    Set the paper orientation to **Landscape** in your print settings, as timetables typically have many columns.
  </Card>
  <Card title="Toggle the axis">
    Use the axis toggle button to switch between "days as rows" and "periods as rows," then choose whichever fits the paper size better.
  </Card>
  <Card title="Adjust the font size">
    Use the 3 zoom levels to find the right size. The smallest level uses 10px, the medium level 13px, and the largest level 15px.
  </Card>
</Cards>

## Configuring Card Mode Before Printing

Before printing, you may want to customize which fields appear in the cards:

| Category | Available Fields | Default |
|---|---|---|
| Teacher | Code, Prefix, First Name, Last Name, Department | First Name, Last Name |
| Subject | Subject Code, Subject Name | Subject Code |
| Student | Code, Class, Grade Level | Class |
| Room | Room Code, Room Name, Description | Room Code, Room Name |

<Callout type="info">
  You can select up to 2 fields per category. For printing, it is recommended to choose concise fields to avoid text being cut off.
</Callout>

## Hiding Unnecessary Information

When viewing the Teacher View, you may not need the teacher's name repeated in every cell of the table. Use the **Hide when viewing own category** option in the display settings to hide redundant rows, making the table more compact for printing.

## Save as PDF

If you want to save the timetable as a PDF file instead of printing on paper:

1. Press `Ctrl+P` / `Cmd+P`.
2. In the **Destination** field, select **Save as PDF**.
3. Click **Save**.
