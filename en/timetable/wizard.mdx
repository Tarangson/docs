## Overview

The Timetable Creation Wizard is a 6-step process that helps you set up all the foundational data needed for scheduling. These steps appear after you create a new timetable file.

## The 6 Wizard Steps

<Steps>
  <Step title="File Information">
    Enter the file name, start date, end date, and additional details (see the [Create a Timetable File](/timetable/create-file) page for more information).
  </Step>

  <Step title="Timetable Structure">
    Set up the base timetable structure, including:

    - **School days** — Select the days you want (Monday through Sunday).
    - **Period label** — Choose from `Period`, `Hour`, `Class Hour`, or specify a custom label.
    - **Number of periods** — Set the number of periods per day (1–20 periods).
    - **Period times** — Specify the start and end time for each period, or use the **Calculate Times** button to auto-generate them based on minutes per period and break duration.
    - **Timezone** — For schools outside Thailand. The default is `Asia/Bangkok`.
  </Step>

  <Step title="Teachers">
    Review and edit the list of teachers. The system automatically pulls data from the school database. You can:
    - Use the existing data as-is.
    - Edit, add, or remove entries.
    - Drag to reorder the list.
    - Search by name, code, or department.

    Teacher data includes: **Code**, **Prefix**, **First Name**, **Last Name**, and **Department**.
  </Step>

  <Step title="Students">
    Review and edit the list of student groups (classes/sections). Student data includes: **Code**, **Class/Section**, and **Grade Level**.
  </Step>

  <Step title="Rooms">
    Review and edit the list of rooms. Room data includes: **Code**, **Room Name**, and **Description**.
  </Step>

  <Step title="Subjects">
    Review and edit the list of subjects. Subject data includes: **Subject Code** and **Subject Name**. Click **Finish** to complete the wizard and enter the timetable editing page.
  </Step>
</Steps>

<Callout type="info">
  At each wizard step, you have two options: **Use existing data** (from the school database) or **Edit** to modify the data before proceeding.
</Callout>

## Automatic Time Calculation

In the **Timetable Structure** step, you can use the automatic time calculation feature:

1. Enter the start time for Period 1, e.g., `08:30`.
2. Set the **Minutes per period**, e.g., `50` minutes.
3. Set the **Break between periods**, e.g., `10` minutes.
4. Click **Calculate Times** — the system will automatically calculate the start and end times for every period.

## Wizard Templates for Special Periods

In addition to the basic Timetable Creation Wizard, the system also provides a **Special Period Wizard** (Wizard Template) for scheduling periods with complex configurations, such as activities involving multiple teachers or multiple student groups.

### Configuration Modes (WizardConfigMode)

Each template defines a mode for teachers, students, and rooms as follows:

| Mode | Description |
|---|---|
| `none` | Not required |
| `single` | Select one item |
| `multi` | Select multiple items |

  <Tab title="Student Assembly (ประชุมผู้เรียน)">

    - Teachers: **multi** (multiple)

    - Rooms: **single** (one room)

  <Tab title="Scouts & Girl Guides (ลูกเสือ เนตรนารี)">

### How to Use the Special Period Wizard

<Steps>
  <Step title="Open the scheduling assistant menu">
    On the timetable editing page, click the **Advanced Scheduling** menu and select **Special Period Wizard**.
  </Step>

  <Step title="Select a template">
    Choose the template that matches the type of period you want to schedule, or select **Custom** to configure it yourself.
  </Step>

  <Step title="Select subject, periods, and participants">
    Choose the subject, day, period, and the list of teachers, students, and rooms according to the selected template's configuration.
  </Step>

  <Step title="System checks for conflicts">
    The system will verify that all selected items are available during the chosen period. If any item is already occupied, you will be notified.
  </Step>

  <Step title="Save">
    Once the validation passes, the system will automatically save the data for all selected items.
  </Step>
</Steps>

### Deletion Assistant

In addition to the creation wizard, there is also a **Deletion Assistant** that helps you find and remove special periods created by the scheduling wizard. The system will display all special periods with their day, period, subject, teachers, students, and rooms, allowing you to delete them one by one.

<Callout type="warning">
  Deleting through the Deletion Assistant will remove the timetable data for all associated teachers, students, and rooms at once.
</Callout>
