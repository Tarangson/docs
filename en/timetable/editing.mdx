## Overview

The timetable editing page is the main interface for creating and modifying your timetable. You can schedule periods by selecting data and clicking on the grid. The system automatically checks for conflicts to prevent double-booking.

## Editing Page Structure

The timetable editing page consists of three main sections:

- **Sidebar** — A menu for selecting the scheduling mode, such as standard scheduling, advanced scheduling (creation wizard, deletion assistant, schedule by individual teacher/student/room).
- **Grid** — A table showing periods by day and period number. You can toggle the axis between "days as rows" and "periods as rows."
- **Toolbar** — Tools for zooming, toggling the axis, display settings, and filtering the list.

## Scheduling Views

You can choose from three views for scheduling:

| View | Description |
|---|---|
| **Teacher View** | Schedule by selecting a teacher first, then assign subjects, students, and rooms to periods. |
| **Student View** | Schedule by selecting a student group first, then assign teachers, subjects, and rooms. |
| **Room View** | Schedule by selecting a room first, then assign teachers, subjects, and students. |

You can switch views from the dropdown in the page header.

## Scheduling Periods

<Steps>
  <Step title="Select a file and view">
    When you open the timetable editing page, the system will prompt you to select the file you want to work with. Then choose a scheduling view (Teacher / Student / Room).
  </Step>

  <Step title="Select the primary item">
    Select the teacher, student group, or room you want to schedule from the list on the left side. The system will load and display their current timetable.
  </Step>

  <Step title="Select data for the period">
    Select the subject, and the associated teacher/student/room from the data selection panel beside the grid.
  </Step>

  <Step title="Click on the grid">
    Click on an empty cell in the grid (the intersection of a day and a period) to place the scheduled period. The system saves automatically.
  </Step>
</Steps>

## Conflict Detection

The system automatically checks for conflicts when you schedule a period, preventing the following issues:

<Cards>
  <Card title="Teacher Double-Booking">
    The same teacher is assigned to more than one period at the same time.
  </Card>
  <Card title="Student Double-Booking">
    The same student group is scheduled for more than one subject at the same time.
  </Card>
  <Card title="Room Double-Booking">
    The same room is assigned to more than one period at the same time.
  </Card>
</Cards>

When a conflict is detected, the system will display the items that are already occupied during that period and prompt you to either reschedule the conflicting item or choose a different period.

## Moving Periods (Drag and Drop)

You can move a previously scheduled period by dragging it from its current cell and dropping it into a new cell within the same grid.

<Callout type="info">
  Pinned periods cannot be dragged or deleted. You must unpin them first.
</Callout>

## Pinning Periods (Pin/Lock)

The pin feature locks a period in place to prevent it from being accidentally moved or deleted. Pinned periods display a yellow pin icon on the card.

**How to pin:**
- Right-click on the period card and select **Pin**.

**How to unpin:**
- Click the pin icon on the card. The system will ask for confirmation before unpinning.
- Alternatively, right-click on the pinned card and select **Unpin**.

## Right-Click Context Menu

When you right-click on a period card in standard scheduling mode, a context menu appears with the following options:

| Command | Description | Available When |
|---|---|---|
| **Copy** | Copy the period data (subject, teacher, student, room) to the selection panel | All periods |
| **Cut** | Copy the period data and remove the original period | Unpinned periods |
| **Delete** | Remove the period | Unpinned periods |
| **Pin** | Lock the period to prevent moving or deleting | Unpinned periods |
| **Unpin** | Unlock the period to allow moving or deleting | Pinned periods |

<Callout type="tip">
  After copying or cutting, you can click on an empty cell in the grid to paste the copied data. The data will be automatically loaded into the selection panel.
</Callout>

## Search and Filter

You can search and filter the primary list (teachers, students, or rooms) from the sidebar:

- **Search** — Type a name, code, or other information to search.
- **Filter** — Filter by custom fields of the select type, such as department or grade level.
- **Sort** — Sort from A–Z or Z–A.

## Switching Files

You can switch to a different timetable file by clicking the file name in the header. The system will display a dialog for selecting a new file without leaving the editing page.

## Schedule Entry Data Structure

Each schedule entry (`ScheduleEntry`) stores the following data:

| Field | Description |
|---|---|
| `id` | Unique period ID |
| `dayOfWeek` | Day of the week (MON, TUE, WED, THU, FRI, SAT, SUN) |
| `periodKey` | Period number (1, 2, 3, ...) |
| `teacherId` | Teacher ID (or multiple IDs separated by commas for special periods) |
| `subjectId` | Subject ID |
| `studentId` | Student ID (or multiple IDs separated by commas) |
| `roomId` | Room ID (or multiple IDs separated by commas) |
| `specialPeriods` | Special period data (created by the Wizard Template) |
| `isPin` | Pin status (`true` = locked) |
