## Overview

The File Management page (`/timetable/files`) is the central hub for viewing and managing all of your school's timetable files. You can view the file list, create new files, open and manage data within a file, or delete files you no longer need.

## File List Page

The file list page displays data in a table with the following columns:

| Column | Description |
|---|---|
| **#** | Row number |
| **File Name** | The file name and description (if any) |
| **Created By** | Name or email of the file creator |
| **Date Created** | Date and time the file was created |
| **Last Modified** | Date and time of the last modification |
| **Manage** | Button to open the file data management page |
| **Delete** | Button to delete the file |

## Searching for Files

Use the search box at the top of the table to find files. You can search by:

- **File name**
- **Description**
- **Creator's name**
- **Creator's email**

Click the **X** button in the search box to clear the search query.

## Pagination

When you have many files, the system will paginate the list. You can:

- Choose the number of rows per page: **10**, **25**, **50**, or **100** rows.
- Use the left/right arrow buttons to navigate between pages.
- View your current position, e.g., "Showing 1–25 of 42."

## Creating a New File

Click the **Create New File** button at the top-right corner. The system will take you to the new file creation page (`/timetable/new`).

## Managing Data Within a File

Click the **Manage** icon (Database) in the row of the file you want to manage. The system will take you to the file data management page (`/timetable/files/{fileId}/manage`), which includes the following features:

<Tabs>
  <Tab title="Teachers">
    View and edit the list of teachers in the file. Data includes:
    - **Code** (code)
    - **Prefix** (prefix) — selected from a predefined list
    - **First Name** (firstName) — required field
    - **Last Name** (lastName)
    - **Department** (department) — selected from a predefined list
    - Additional custom fields
  </Tab>

  <Tab title="Students">
    View and edit the list of student groups in the file. Data includes:
    - **Code** (code)
    - **Class/Section** (className) — required field
    - **Grade Level** (gradeGroup) — selected from a predefined list
    - Additional custom fields
  </Tab>

  <Tab title="Rooms">
    View and edit the list of rooms in the file. Data includes:
    - **Code** (code)
    - **Room Name** (name) — required field
    - **Description** (description)
    - Additional custom fields
  </Tab>

  <Tab title="Subjects">
    View and edit the list of subjects in the file. Data includes:
    - **Subject Code** (code) — required field
    - **Subject Name** (name) — required field
  </Tab>
</Tabs>

### Data Management Features

- **Add an item** — Click the add button (e.g., **Add Teacher**) to open a data entry dialog.
- **Edit** — Click the edit icon (pencil) in the row you want to modify.
- **Search** — Type to search across the various fields for each data type.
- **Sort** — Click a column header to sort from A–Z or Z–A.
- **Pagination** — Choose the number of items per page (10, 20, or 50).
- **Timetable status** — A green calendar icon indicates that an item already has timetable data (except in the Subjects tab).

## Deleting a File

<Steps>
  <Step title="Click the delete button">
    Click the **Delete** icon (trash can) in the row of the file you want to delete.
  </Step>

  <Step title="Confirm the deletion">
    The system will display a confirmation dialog showing the name of the file to be deleted. Click **Delete File** to confirm, or **Cancel** to go back.
  </Step>
</Steps>

<Callout type="warning">
  When you delete a file, all data within it will be permanently removed, including:
  - All timetables
  - Teacher list
  - Student list
  - Room list
  - Subject list

  This action **cannot be undone**.
</Callout>

## Switching Between Files

When you are on the timetable editing page or the timetable viewing page, you can switch files in two ways:

1. **From the File Management page** — Return to this page and open the file you want.
2. **From the file selection dialog** — On the editing or viewing page, the system prompts you to select a file when you first enter the page, or you can switch files using the dropdown in the header.
