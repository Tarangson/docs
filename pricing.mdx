ตารางสอน ให้ใช้งานฟรีทั้งหมด**ยกเว้นฟีเจอร์ AI และการตรวจจับความขัดแย้งขั้นสูง** ซึ่งอยู่ในแพ็กเกจ **Academic Pro**

## เปรียบเทียบแพ็กเกจ

| ฟีเจอร์ | Free | **Academic Pro** |
| --- | :---: | :---: |
| ราคา | 0 บาท | **฿999 / ปี** |
| จำนวนแฟ้มตารางสอน | ไม่จำกัด | ไม่จำกัด |
| จำนวนผู้สอน / ผู้เรียน / ห้อง / วิชา | ไม่จำกัด | ไม่จำกัด |
| ลากวางจัดตารางเอง | ✅ | ✅ |
| ตรวจจับความขัดแย้ง real-time | พื้นฐาน | ✅ เต็มรูปแบบ |
| AI จัดตารางสอนอัตโนมัติ | ❌ | ✅ |
| นำเข้า/ส่งออก Excel | ✅ | ✅ |
| พิมพ์ตารางสอน | ✅ | ✅ |
| พิมพ์รายงานหลายรูปแบบ | พื้นฐาน | ✅ 7 แบบ |
| ผู้ใช้ร่วม (เชิญเพื่อนร่วมงาน) | ✅ | ✅ |
| สนับสนุนทางอีเมล | ✅ | ✅ พิเศษ |

<Tip>
  ราคา ฿999/ปี คิดเป็นเพียง **฿2.74/วัน** ต่อทั้งโรงเรียน ไม่จำกัดจำนวนผู้ใช้ร่วม
</Tip>

## ดูแพ็กเกจปัจจุบันของคุณ

<img src="/images/screens/settings-package.png" alt="หน้าแพ็กเกจในตั้งค่า" />

เข้าไปที่ **ตั้งค่า > แพ็กเกจ** หรือกดที่ชิป **"Academic Pro"** / **"Free"** มุมขวาบนของหน้าจอ ระบบจะแสดง:

- **ชื่อแพ็กเกจปัจจุบัน** พร้อมป้าย **"ใช้งาน"**
- **ราคา** (เช่น 999.-/ปี)
- **วันที่เริ่ม** และ **วันหมดอายุ** พร้อมนับจำนวนวันคงเหลือ
- ลิงก์ **"เปรียบเทียบแพ็กเกจทั้งหมด"** เพื่อดูตารางเปรียบเทียบแบบเต็ม

## วิธีอัปเกรดเป็น Academic Pro

<Steps>
  <Step title="เปิดหน้าแพ็กเกจ">
    กดที่ชิปแพ็กเกจมุมขวาบน หรือไปที่ **ตั้งค่า > แพ็กเกจ**
  </Step>
  <Step title="กดปุ่มอัปเกรด">
    กดปุ่ม **"อัปเกรดเป็น Academic Pro"** หรือ **"เปรียบเทียบแพ็กเกจทั้งหมด"**
  </Step>
  <Step title="เลือกวิธีชำระเงิน">
    รองรับ QR PromptPay / โอนผ่านธนาคาร / บัตรเครดิต — ดูที่ **ตั้งค่า > การชำระเงิน**
  </Step>
  <Step title="ยืนยันและเริ่มใช้งาน">
    เมื่อชำระเสร็จ ระบบจะอัปเดตแพ็กเกจภายในไม่กี่นาที ฟีเจอร์ AI และฟีเจอร์ Pro ทั้งหมดจะพร้อมใช้งานทันที
  </Step>
</Steps>

## ต่ออายุแพ็กเกจ

เมื่อใกล้หมดอายุ (30 วันก่อน) ระบบจะส่งอีเมลแจ้งเตือนและแสดงแบนเนอร์ในแอป — กดปุ่ม **"ต่ออายุ"** ในหน้าแพ็กเกจเพื่อชำระเงินรอบถัดไป

<Warning>
  หากปล่อยให้หมดอายุ แพ็กเกจจะย้อนไปเป็น **Free** โดยอัตโนมัติ ข้อมูลทั้งหมดยังอยู่ครบ แต่ฟีเจอร์ AI จะถูกล็อก
</Warning>
